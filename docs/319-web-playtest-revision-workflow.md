## 实际使用中修复的保存问题

首次浏览器流程在主页/刷新/重开后导出工程失败，按钮显示保存冲突。原因是 `useRef(createBrowserWriterLeaseOwnerId())` 在每次组件渲染都执行生成器，把 sessionStorage 改成未使用的 owner；快速导航刷新时旧租约尚未释放，重新打开就会使用错误 owner。

改成一次状态初始化，并在取得租约后记住真正 owner，兼顾 StrictMode 重复初始化。普通渲染/实际持有者/卸载交接及既有重载/独立窗口策略的相关测试通过，实际快速刷新后保存和导出成功；未改底层租约或强制接管其他窗口。
