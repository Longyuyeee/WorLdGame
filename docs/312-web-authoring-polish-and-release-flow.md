# Web 创作界面收尾与作品交付流程

2026-10-14；起点 `9376cc3`；接续 #304、#311。

## 本批用户任务

作者打开工程后能看懂演出列表，写作时只看到当前操作所需内容；试玩时可以继续、回退和选择，不被开发工具挤出预览栏。遇到演出等待或不兼容修改，必须能看见恢复入口。需要调试时主动展开详细工具。

发布只围绕 Web：配置作品、选择文件形式、生成、下载和验证。导出成功不等于已经上传网站。目录包提供部署步骤与玩家回查清单，不要求先选平台。工程改变后旧导出必须失效。

沿同一《雨停之前》工程做文字校订，保留场景、正文键和分支，重新导出可编辑工程及两种 Web 产物。校订属于本次编辑复核，不冒称真人自然阅读、实际手机或发行许可通过。

## 实施顺序与必要验证

1. 将演出参数转换成可读摘要，原始信息保留在主动展开的技术详情。
2. 分开场景预览与完整试玩；收纳调试和已完成演出记录，保持需要确认的操作可见；核对窄预览栏和手机布局。
3. 收尾 Web 发布步骤与导出后的部署引导，移除本轮未交付的平台占位。
4. 校订作品、保存重开、重新导出并用真实浏览器走两路线、存读档及目录本地站点。
5. 仅跑相关回归、类型及所需生产构建，记录失败和未跑项目，不追加全仓审计。

## 结果

### 已交付

- 写作页的背景、角色、音频、镜头和对白框使用中文摘要，素材显示名称；不明确的旧参数提示展开检查。可访问名称同步更新，脚本参数保留在主动展开的详情里。
- 当前文字进入编辑时不重复铺出整段正文；试玩位置显示场景名和步骤，安全区默认关闭。场景预览的播放条在完整试玩中收起；回退、前进和继续故事保留，单步/运行到选中步骤、已执行演出和诊断分别收纳。等待确认与不兼容修改的恢复入口仍可见。
- 实际检查 1440/1280 预览栏、清亮/石墨主题后，修正按钮字号、深色退出按钮与主操作对比。Web 发布增加第四步“试玩与部署”，移除原生平台占位；390 宽度的下载结果提前显示。
- 通过真实 Editor UI 校订《雨停之前》四段旁白，发布版本为 **1.5.1**。补慢钟伏笔、统一课程时间、说明留下路线次日改签与线上试合作、明确远行路线周末时间推进。仍为待定稿候选，具体修改见 `assets/rain-story/editorial-v1.5.1.mjs`。保存、关闭、刷新、重开通过；9 场景/90 段旁白/9 句对白/**9,626 字符**/71 步演出保持，只有四段旁白改写，所有正文键、场景/语句 ID、选择、演出及源媒体未变。
- 同网址更新实查发现旧版快速读取失败后，错误仅存在于关闭的面板，玩家没有反馈。现在自动打开对应存档页、显示失败原因及原存档保留说明，提供“返回故事”；菜单与自动推进仍沿原存档面板保护。最终 1.5.1 包实际拒绝 1.5.0 的旧档，当前剧情不变，回到 1.5.0 可读取原档。**这是明确不兼容并保留旧档，不是完成旧档迁移。**

### 必要验证与原始失败

最终所选 **23 个不同测试通过**，不累计重复运行：4 个组件文件选 19 项（最终整组 18 通过/1 个长流程超时；该项独立在 30 秒上限内通过，测试执行 11.70 秒）；PlayerShell 只选手动/快速存读档 3 项，另 77 项未选；Sequence 只选当前运行位置/可访问名称 1 项，另 1 项未选。相关日志为 `regression-final.log`、`continuity-focused.log`、`save-feedback-regression.log`、`sequence-accessibility.log`。跨多工作区往返的那个 jsdom 长流程设置单独 30 秒上限；这不是实际 UI 耗时或性能达标证据。

首次默认 5 秒超时，后续用例当时停在启动页；15 秒复跑曾整组通过，但最终整组该长流程仍超时。原始结果保留，独立复跑后停止扩大测试。新增测试误用 Playwright 的 `exact` 参数于 Testing Library，类型检查拒绝，改正后通过。读取失败反馈问题有真实同源替换复现；`update-failure.png` 是修正前的玩家无反馈画面，`ui-review.log` 记录该失败，不能当作最终通过。

最终生产构建浏览器 **6 组检查通过**，错误数组为空，浏览器为本机 Chromium **155.0.8059.41**。覆盖可读演出/原始详情、两种主题/窄栏布局、实际四段校订与重开/三产物、稳定 ID 和源媒体保护、HTML 留下路线、HTTP `/gal/` 手机尺寸远行路线，以及同源旧档拒绝/回到原版仍可读取。两路线各走完 60 段旁白/6 句语音，自然等待所用 TTS 结束，并中途快速保存、刷新和读取。截图已目视核对。手机尺寸/触控上下文不等于手机真机；自动点击不等于人工阅读。报告 `browser-checks.json`、`update-checks.json`；旧 `browser-before-save-feedback.*` 是修正前产物的历史结果。

最终类型检查、Editor/Player 生产构建通过，均保留 >500kB chunk 提示。未运行完整 check、全仓/所有 Editor、历史 goldens、所有浏览器引擎、物理手机、完整无障碍、长期运行或旧长帧预算。没有公网发布、素材许可确认或最终作品验收。
