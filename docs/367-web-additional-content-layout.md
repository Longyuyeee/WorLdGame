## 作者从哪里使用

进入“游戏外观 → 其他页面 → 附加内容”，再选择“附加内容布局页面”。总览和四个分组的位置、尺寸、手机配置及最多六个文字／图片／返回按钮分别保存；字体、底色、背景和窗体风格仍由附加内容共用。关闭某一页自由布局只恢复该页模板，不隐式继承总览的组件，不改变其他分组。

五页继续使用正式 Player 的画布选择、拖动、尺寸调整、键盘微调、一次手势一次撤销、锚点、安全间距和设备可见性。内容可独立滚动，原返回控件保留；冲突的额外按钮并入内容操作区。旧宽度、位置、整页入场动效和面板预设在本页启用自由布局时明确禁用，避免调整无效参数。

实际预览可直接切到各分组，空白工程也有可读的空状态。预览不会为作者伪造收藏解锁或回想入口，不写正式玩家进度；完整解锁仍需实际游玩原路线。

## 玩家返回与内容保护

总览的额外返回回到原来的标题、正文或结局；分组的额外返回只回收藏总览。分组原生“返回总览”和整页“返回剧情”放在独立返回区，正文滚动不带走它们；返回后焦点回到原分组入口。新页只接受返回动作，不新增直接解锁、播放、启动回想、读档确认或任意脚本动作，真实内容操作仍由原控件和服务完成。

画廊大图是独立子弹层，移到滚动列表之外，不受内容区的尺寸容器裁切。图片完整显示并保留比例，图名与至少 44px 的关闭按钮独立排版，遵守顶部宿主栏和设备安全区。打开后底层列表／额外按钮隐藏，Tab 留在大图内；Esc 先关大图，再返回总览，最后退出附加内容。图片关闭后回到原缩略图；若资源或入口已消失，则回到分组返回按钮。资源在打开后丢失或加载失败时仍显示可关闭的提示，不留下空白死路。

音乐室继续使用浏览器原生试听控件，音量／静音沿用玩家设置和作品混音。测量、横竖屏或普通参数更新不替换音频元素，也不重置试听位置。离开音乐室、替换音源或卸载时明确暂停实际元素，宿主暂停时也停止试听；重新前台不自动播放。回想、解锁、收藏记录、父剧情恢复与存档格式沿用既有权威。

五个布局字段均可选，旧配置无需补字段。统一的可选页面列表用于校验、图片引用和重映射；桌面专属图片仍打包，缺图仍可重新对应或回退。带新字段的皮肤需当前版本读取，不承诺旧应用可读。

## 本批发现与修正

截图复查发现原音乐卡片预留了封面列，无封面的试听控件因此挤在很窄的一列。现按封面和实际内容区宽度排列，窄区使用单列内容和独立回想按钮。原画面保留为 [audit-before-music-sizing.png](../evidence/web-additional-layout/audit-before-music-sizing.png)，最终浏览器流程增加了原生控件的实际宽度断言。

继续检查退出试听时，确认音频节点移除后仍在播放。新增只管理原生音频生命周期的组件，卸载／换源／宿主暂停时显式暂停，不在普通重排时清空位置。失败 `failure-2026-10-16T19-57-16-853Z.*` 保留；最终双格式均持有原节点，实际播放后离开分组，确认该节点已暂停，而不只检查页面上的音频控件消失。

## 验证结果

[250 项相关回归、39 文件通过](../evidence/web-additional-layout/unit-tests.json)：涵盖十一种可选布局的旧配置往返、严格动作与引用、最小视口、五页制作／撤销、空工程预览、带素材复用、锁定信息、图片资源丢失、子弹层焦点、音乐元素保持与释放、回想精确恢复，以及既有阅读、设置、名单、存读档、收藏和导出。根类型检查、Editor／Player 生产构建及 118 便携／4 Node 适配文件架构审计通过。jsdom 不提供真实音视频；构建仍有大 chunk 提示。

[五组实际静音浏览器流程通过](../evidence/web-additional-layout/browser-checks.json)：

1. 在主样章逐页制作五页桌面／手机布局，真实拖动在松开后提交，一次撤销恢复，方向键微调；编辑框和 Player 内容区按 1.5px 容差对齐。
2. 应用、保存、返回列表重开，再导出工程、皮肤配置、带素材皮肤和两种游戏。双游戏外观等于源工程；原剧情、角色、七素材及原八页布局保持，正式游戏没有编辑预览标记。
3. 独立桌面 HTML `file://`：锁定条目不提前显示，五页的返回层级、原句保持、大图比例／关闭／焦点、实际静音试听与暂停位置、退出后停止、第一条完整路线、回想恢复父状态摘要／宿主摘要／历史游标、确认读档回原句及刷新保留收藏。
4. 独立触屏目录 HTTP：390×844、844×390、390×480 下逐页核对返回控件、图片关闭和试听位置；完成另一条路线、退出试听和回想、确认读档及刷新后的结局收集。两种独立游戏各达成一条，合计两结局 **2/2**，不是全格式×路线矩阵。
5. 空白第二工程导入同一带素材皮肤，五页布局及仅桌面显示的图片进入工程，原脚本与角色文件逐字节不变，实际音乐室预览仍可编辑。

目录 18 个文件大小和摘要核验通过。试听检查使用真实媒体元素与静音浏览器，不计为听感验收。编辑器整部路线未重跑；桌面 Chromium 的触屏／横竖屏不替代物理手机或 Safari。
