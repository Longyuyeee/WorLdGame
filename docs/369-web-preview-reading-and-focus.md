## 作者如何使用

故事页的“即时预览”现在将舞台与正文分开。舞台继续使用工程画幅和原 Canvas／Host 演出；正文、选择、等待和结局仍来自同一剧情投影与正式 Runtime，不复制一套运行逻辑。文字区明确标为作者校订视图；最终游戏的窗体、字体、NVL／气泡等排版继续在“游戏外观”的真实 Player 和导出的游戏中核对。

正文区可以用滚轮、触控或键盘阅读，长段落不会被舞台裁切，也不会为了看末行而推进剧情。新 ADV 语句从头显示；NVL 新语句将自己的滚动区移到最新内容。同一句布局重绘不主动重置手动滚动位置，改变宽度或字号仍按新排版显示。编辑器明暗主题使用既有颜色变量，高对比和减少动效仍有独立回退。

点击“专注预览”，或在当前校订任务点击“查看试玩画面”，可收起编辑区、任务详情与视图导航；桌面放大舞台并将运行控制置于侧栏，窄屏按内容顺序排列。主导航和“返回编辑布局”仍可使用，任务不是删除或结束。退出后恢复原来的编辑／校订界面，不重新启动试玩。

在预览内按 Esc 可退出专注并将焦点放回切换按钮；输入法组合、下拉框或模态对话框的 Esc 不被抢走。专注不是浏览器全屏或新窗口，不需要全屏权限，也不把布局偏好写入作品。关闭重开工程后回到普通布局，不恢复已结束的运行态或旧复核资格。

## 运行与编辑保护

布局变化复用同一 Canvas、音频元素与正式试玩状态，不重新导入素材或启动另一套会话。Runtime 状态、History、已记录未来、Host 与工程引用在集成测试中保持同一对象；真实浏览器另检查画布像素、当前句、历史游标及两个静音播放音轨的位置和元素身份。

正文不再属于空间编辑表面。读正文不会改变人物坐标；在实际舞台点按仍通过稳定语句 ID 写回规范命令。专注状态暂停隐藏写作区的 Ctrl+Enter 插入与 Alt+1 至 Alt+5 演出快捷键，防止阅读时在后台插入内容；返回编辑布局后恢复。原草稿保护、手动确认、回退／前进、分支和跨结构接续继续有效。

## 本批问题与修正

原 299×168px 的窄舞台中，正文纵向覆盖约 156px，部分文字还超出舞台被裁掉。[基线截图](../evidence/web-preview-reading/baseline-long-paragraph.png)与[测量](../evidence/web-preview-reading/baseline.json)由改动前的 97a5087 生产包采集。现在普通窄预览和专注预览的舞台／正文重叠均为零；本机桌面专注舞台约为 818×460px，仍是原 16:9，不改工程构图。

截图审查修复了手机单列网格被压缩、运行控件盖在舞台上的问题，改为按内容确定行高；[修正前画面](../evidence/web-preview-reading/audit-before-mobile-track-sizing.png)保留。专注时收起任务详情和视图导航，使 844×390 短横屏也能在可滚动预览面板内完整显示等比舞台。普通演出布局保留可滚动的最小行高，不再被大校订任务挤到零高度；演出与专注布局切换的样式优先级冲突也已修正。

其他过程失败保留为同目录 `failure-*` 和 `initial-regression-tests.json`：旧空间编辑测试点击已移出的文字层，现改为验证“文字不定位、舞台才定位”；流程脚本修正了任务阶段、刷新后所在页面、手机隐藏撤销按钮、布局过渡采样及 ZIP 整包摘要的错误假设。目录最终按运行代码、工程、素材与文件清单核对，没有把不同容器摘要直接记为同一包。

## 验证结果

2. 390×844、844×390、320×740 下正文与舞台、运行控制均不重叠，滚动后完整舞台在面板内可见；9:16、4:3、超宽和 16:9 预设保持比例，End 阅读末行不翻句，Esc 返回原按钮。[竖屏](../evidence/web-preview-reading/focus-390x844.png)、[短横屏](../evidence/web-preview-reading/focus-844x390.png)。

5. 编辑器在新正文区正常选择分支，从入口分别到达“同行的约定”和“远行的约定”，当前两结局 **2/2**；十一条记录导出与原文件内容一致，未自动复核。
6. 保存、刷新、重开后不自动恢复试玩或专注状态。导出工程 65 个条目逐字节等于原工程；实际 HTML 摘要与 #368 相同，目录的 Runtime／CSS 等于该 HTML，工程与 25 媒体一致，35 个清单文件大小／摘要通过。临时导出包只做核对，没有重复入库或产生新发行版本。

本批没有重跑独立 Player 两路线；对应记录仍是 #368 的桌面 HTML 一路、触屏尺寸 HTTP 另一路，合计 2/2，非格式×路线矩阵。本批导出一致性不冒充新增独立通关。以上桌面浏览器尺寸模拟和静音检查也不替代真机／Safari、人工自然阅读、听感、美术、长时间稳定性、许可或公网验收。
