# 路线图与评审门

## 1. 原则

- 先验证最危险的技术和交互假设，再扩展功能。
- 每阶段有退出条件，不能以“已经写了很多代码”代替完成。
- 未通过评审门不得进入下一阶段。
- 最终愿景完整，首期范围克制。

## 3. D0：调研与定位（当前）

### 交付

- 竞品分析；
- 产品战略；
- PRD；
- UX 信息架构；
- 技术架构；
- 工程格式与质量体系；
- 开放决策。

### 退出条件

- 产品负责人确认首要用户；
- 确认 P0 与明确排除项；
- 确认工作名/品牌另行处理；
- 批准进入低保真原型；
- 不需要产品代码。

## 4. D1：交互原型

### 范围

- 桌面 Route、Sequence、Script、Stage；
- 手机写作、路线、舞台、预览和构建流程；
- 本地化表与 QA 报告；
- 构建失败向导。

### 方法

- 可点击原型或静态高保真；
- 使用真实长度台词和复杂分支；
- 至少 5 名目标用户；
- 同任务对比 WebGAL、Naninovel Story Editor 或可用同类。

### 退出条件

- 8/10 核心任务无需指导完成；
- 用户理解四视图是同一内容；
- 手机连接分支和修改演出没有致命阻塞；
- 无需推翻信息架构。

## 5. S0：技术 Spike

### 范围

- 10k Route 节点局部渲染；
- 100k 行增量解析；
- 双向 Round-trip；
- Android 文件/键盘/内存；
- PixiJS + DOM；
- 保存/回滚；
- Electron/Tauri 对比；
- Capacitor；
- 四平台最小构建；
- OPFS 恢复；
- 插件未知命令保留。

### 退出条件

- 所有 Spike 有数据和结论；
- 失败项有替代方案；
- 技术选型形成 ADR；
- 性能预算没有结构性不可达项；
- 产品负责人明确批准开始产品编码。

## 6. M1：核心纵向切片

### P0

- 项目创建/打开/自动保存/恢复；
- 基础工程格式、Parser、AST、Compiler；
- Route、Sequence、Script、Stage 基础同步；
- 对话、背景、角色、音频、选择、变量、条件、结局；
- 即时预览与变量查看；
- 保存、读取、回滚、历史、自动和跳过已读；
- 结构 QA；
- Windows 与 Android 编辑；
- Web 与 Windows 玩家包；
- 工程导入导出和离线使用。

### 退出条件

满足 PRD 的 10 条纵向切片验收，且：

- 无 P0 数据丢失；
- Golden Tiny/State/CJK 通过；
- Windows 与 Android 同项目连续编辑一周；
- Web/Windows 固定路线状态一致；
- 20 名内部/受邀创作者完成短篇。

## 7. M2：创作者 Alpha

### 范围

- 资源管理、压缩和批量操作；
- UI 主题基础；
- 本地化 CSV/XLSX；
- 语音映射；
- Android 玩家包/云构建；
- 高级搜索、重构和调试器；
- 路线录制和覆盖；
- 模板与新手教程；
- 基础可访问性。

### 退出条件

- 100 名创作者；
- 至少 20 个完整短篇发布；
- 首次成功 Web 构建中位时间符合目标；
- 构建成功率达到 95%；
- 工程恢复演练成功；
- Alpha 格式迁移到下一版本无静默损失。

## 8. M3：生产 Beta

### 范围

- iOS 构建和签名；
- 完整 UI Composer；
- CG/回想/音乐室；
- 章节下载与补丁；
- 结局可达性、路线覆盖、存档兼容 QA；
- 云同步和版本历史；
- 评论、审阅和基础权限；
- 插件 SDK；
- Live2D/Spine 适配；
- Steam/itch.io 发布辅助。

### 退出条件

- 3 个 10 万字级项目完成生产；
- 4 平台固定路线与存档一致；
- 旧存档升级测试通过；
- 云端安全评审通过；
- 插件 API 有外部试用；
- 无阻塞级数据损坏问题。

## 9. M4：团队与生态

### 范围

- 实时协作；
- 语义分支/合并；
- 组织权限与审批；
- 插件/主题/模板市场；
- 私有构建节点；
- 翻译、配音、网盘和 Git 连接器；
- 可选 AI 助手；
- 高级 Storylet/动态叙事。

## 10. 工作流

每个里程碑使用：

1. Problem Brief；
2. ADR/交互规格；
3. 可测验收；
4. 实现；
5. 自动化与真实设备验证；
6. 文档；
7. 用户试用；
8. 复盘和下一评审门。

## 11. 不允许的进度定义

以下不能单独作为“完成”：

- 页面看起来像编辑器；
- 节点可以拖动；
- Demo 可以运行一条路线；
- 单个平台成功打包；
- 功能按钮存在但没有失败/恢复路径；
- 只在开发者机器通过；
- 只有云端副本，没有可导出工程；
- 可视化编辑后无法安全回到文本。

## 12. 指标看板

### 创作

- 首个可玩预览时间；
- 每 1,000 字操作数；
- Route/Sequence/Script 使用分布；
- 手机继续编辑率；
- 自动恢复成功率。

### 质量

- 数据损坏/丢失；
- Story QA 发布前检出数；
- 四平台一致性失败；
- 存档兼容失败；
- 崩溃率与 P95 输入延迟。

### 发布

- 首次构建成功率；
- 平均排队与构建时间；
- 平台错误分类；
- 产物体积；
- 从编辑到发布完成时间。
