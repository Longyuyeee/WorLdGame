# 路线图与评审门

## 1. 原则

- 先验证最危险的技术和交互假设，再扩展功能。
- 每阶段有退出条件，不能以“已经写了很多代码”代替完成。
- 未通过评审门不得进入下一阶段。
- 最终愿景完整，首期范围克制。

## 2. 阶段总览

```mermaid
flowchart LR
    D0["D0 调研与定位"] --> D1["D1 交互原型"]
    D1 --> S0["S0 技术 Spike"]
    S0 --> M1["M1 首个正式 Stable 版本"]
    M1 -. "验收后另行决策" .-> Future["M2+ 未排期愿景池"]
```

已确认：当前计划只执行到 M1，且 M1 必须是可正式公开发布的首个 Stable 版本。M2、M3、M4 不删除，但不代表排期、预算或开发承诺。

当前状态：D0 产品决策门已闭合。产品负责人于 2026-08-11 要求继续开发并停止使用 Figma，因此 D1/S0 改用可运行代码原型、自动化测试和真实平台证据。2026-08-12 审计确认执行顺序已偏向 Web 编辑器功能扩展，现按[《S0 收口与方向纠偏审计》](61-s0-closure-course-correction.md)冻结 S0.41 产品代码并关闭剩余高风险；D1、S0、M1 均未通过。

### 2.1 当前强制主路径

```mermaid
flowchart LR
```

- 收口前禁止创建 S0.42 或增加与 CL-01–CL-12 无关的产品功能；
- 每项剩余风险必须输出数据、失败替代、ADR 和可追溯证据；
- Draft PR #1 保持 Draft，产品代码冻结点为 `f16f34d`；
- 详细风险顺序、PR 规则和退出清单以纠偏审计文档为准。

## 3. D0：调研与定位（产品决策门已通过）

### 交付

- 竞品分析；
- 产品战略；
- PRD；
- UX 信息架构；
- 技术架构；

- 已确认覆盖低档 Android 与集显 Windows；能力档位、容量/内存与 Benchmark 分包预算已在 CL-01 冻结，实体设备记录仍待补齐；
- 批准核心工程不变量、信任边界和审计红线；
- 确认工作名/品牌另行处理；
- 批准进入低保真原型；
- 不需要产品代码。

D1 执行包见[《D1 发现与原型计划》](15-d1-discovery-and-prototype-plan.md)、[《D1 视觉系统规格》](16-d1-visual-system.md)、[《校园 Benchmark Episode 设计》](17-benchmark-episode.md)与[《D1 用户验证协议》](18-d1-validation-protocol.md)。

### 范围

- 桌面 Route、Sequence、Script、Stage；
- 手机写作、路线、舞台、预览、工程导出和构建配置流程；
- 本地化表与 QA 报告；
- 构建失败向导；
- 编辑器视觉方向板、设计 Token 和桌面/平板/手机高保真关键屏；

- Benchmark Episode 分镜、素材清单与评分表；
- Optimization Center 的预算、建议、差异对比、应用和回退高保真流程。

### 方法

- 可运行代码原型；不再使用 Figma；
- 强动效部分必须使用可播放高保真原型，不以文字说明代替；
- 使用真实长度台词和复杂分支；
- 至少 5 名目标用户；
- 同任务对比 WebGAL、Naninovel Story Editor 或可用同类。

### 退出条件

- 8/10 核心任务无需指导完成；
- 用户理解四视图是同一内容；
- 手机连接分支和修改演出没有致命阻塞；
- 目标用户能够辨认语义色和七种模式的用途；
- 完整与减少动效方案均通过核心任务，动画不阻塞输入；
- 商业成品评分维度与 Benchmark Episode 方案获批准；
- 无需推翻信息架构。

## 11. 不允许的进度定义

以下不能单独作为“完成”：

- 页面看起来像编辑器；
- 节点可以拖动；
- Demo 可以运行一条路线；
- 单个平台成功打包；
- 功能按钮存在但没有失败/恢复路径；
- 只在开发者机器通过；
- 只有云端副本，没有可导出工程；
- 可视化编辑后无法安全回到文本。

## 12. 指标看板

### 创作

- 首个可玩预览时间；

- Route/Sequence/Script 使用分布；
- 手机继续编辑率；

### 质量

- 数据损坏/丢失；
- Story QA 发布前检出数；
- M1 Web/Windows/Android 一致性失败；未来平台加入后扩展统计；
- 存档兼容失败；
- 崩溃率与 P95 输入延迟。

### 发布

- 首次构建成功率；
- 平均排队与构建时间；
- 平台错误分类；
- 产物体积；
- 从编辑到发布完成时间。
