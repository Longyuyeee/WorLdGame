# Web 连续写作、玩家外观与发布准备

2026-10-14 后续：[#311](311-web-preview-structure-continuity.md) 已完成本文留下的跨结构页运行中试玩连续性：兼容构建保留检查点与历史，不兼容变更明确重启；结构事务和写作撤销仍独立。正式跨场景演出预览与点击区遮立绘问题同时纠偏，具体证据以 #311 为准。下文保留本批当时事实。

日期：2026-10-13。接续 7349685 和 #304/#305。

## 实施前范围与用户任务

沿《雨停之前》继续制作连贯剧情与分支，交付可编辑工程、HTML 和本地子路径部署包。作者编辑一句对白后去创建角色/场景，返回原场景仍可撤销和重做；被结构操作改写的场景须重新建立撤销边界，不能让撤销覆盖新引用迁移。保留当前选中语句及场景，新建场景按用户请求进入。

结构页使用原有保存与修订流程，进入前保存完成，返回时对当前 Canonical 内容校对。连续性仅保留当前内存里的未变场景写作历史和命令计数，不跨工程或浏览器重开恢复撤销；运行中试玩依旧依据当前构建重建，后续连续预览另行治理。

玩家外观允许配置标题简介、夜幕/暖纸配色、紫罗兰/青绿/玫瑰强调色及已导入图片封面。标题、正文、选择、存档和历史使用同一配色，文字大小和消息窗透明度继续复用既有设置。配置随工程保存，HTML/目录导出使用同一内容；素材缺失提供恢复默认入口，禁止任意外部 URL/CSS。封面失败回退可读标题与开始按钮。编辑器主题独立保留。

使用实际界面扩展开场、分支中的对白和演出，完成作者配置、保存重开、两条路线、存档/历史和本地 HTTP 部署。记录实际篇幅，未达到 20–30 分钟则继续保留完整篇幅待办；公网托管目标尚未确定，仍待后续。

必要验证覆盖撤销的保留/重置边界、创建返回、外观保存及安全输入、真实导出产物和两条路线。修改涉及的已有回归、类型与双构建运行后更新 #99，审计、提交并推送。

## 实施结果

- 同一打开工程往返结构页时，比较已保存的 Canonical 场景与原写作内容，保留未改写场景的源文档、注释、撤销/重做、选择位置和命令计数。新增角色和场景不再清空其他场景的写作记录。改写场景重新建立记录；删除角色/场景/变量或改变变量类型会重置先前撤销环境，避免撤销恢复失效引用。创建新场景进入该场景；被删除的当前场景回到工程入口。
- `ui/screens.json` 的可保留扩展字段 `webPlayerAppearance` 保存 v1 外观；其他 UI 字段和旧工程默认外观保留。只接受固定主题/配色和纯文本简介。封面须为已检查、不超过 8 MiB / 4,194,304 像素的 PNG/JPEG/WebP；资源缺失阻止带该封面的导出，玩家读取失败仍能开始。原生 Atlas 组不吞掉封面源图。
- 外观草稿加入离开阻断；应用后再提交文字设置仍保留外观。设置来源默认预览 Web。字体缩放与原文字设置共同进入正式产物，编辑器多主题使用原设计变量；深色输入对比实测 13.11:1，仅覆盖该输入，非全站无障碍验收。
- 实际存档截图发现桌面六槽面板超出舞台，增加高度限制与内部滚动；390 尺寸保持视口内，并实际验证桌面/手机两页槽位均可到达。暖纸标题小字和选择编号对比度也作修正。
- 修复开发服务器的播放器导出包长期缓存：播放器/依赖源码变更使虚拟模块失效，后续构建获取当前运行代码和 CSS。生产构建仍按一次构建生成；此修复不改变已发行作品的更新合同。

所有创作仍通过真实 UI 完成，包括角色选择、对白、选择分支和演出；未直接改 Script/IR 来制作验证工程。可编辑工程、HTML、目录包及实际截图在 `evidence/web-writing-appearance`。本轮仍为短篇，没有计为 20–30 分钟完整作品通过；使用既有测试背景，正式公开发行前需要替换/核实素材授权。
