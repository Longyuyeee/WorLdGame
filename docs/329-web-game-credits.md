# Web 制作名单与作品致谢 · 2026-10-15

接续 `c74f1fd`（#328）。本批沿“定稿 → 填写作品署名 → 保存 → 生成游戏 → 玩家查看 → 交付目录”的流程补齐成品信息入口。

## 已完成

- 发布的“作品信息”页增加制作名单卡片，内容收在独立弹窗中。可填写团队、作品网站、版权说明、素材与特别鸣谢，按顺序添加/上移/下移/移除署名；每条包含职责、姓名或名称及可选链接。最多 80 条署名、12,000 字符致谢，空名单不显示玩家入口。
- 发布名称等有未应用修改时，先应用或放弃再编辑名单。名单弹窗打开时阻止切页，Escape 遇到草稿保留并提示，明确应用或放弃；底部按钮固定、内容单独滚动，手机也能编辑长名单。应用后的信息随 Canonical 工程及原有本机保存/ZIP 备份保留。
- 玩家标题、阅读菜单与普通结局增加“制作名单”。使用现有玩家模态面板和暂停推进机制，背景暂不可操作；Auto 暂停、快进停止，关闭后保持当前剧情，返回原入口或阅读菜单按钮。键盘焦点包含网站/署名链接，Escape 和返回按钮可退出，长内容滚动时保留关闭入口。名单继承作品配色。
- 文本按原文显示，不解释为 HTML；结构化链接只接受完整 HTTP/HTTPS 地址并在新标签打开。导入的名单格式错误会在生成检查中定位到作品信息，作者可明确重填；Player 遇到坏名单隐藏该入口，保留启动能力。
- 正式 HTML 与目录游戏均使用同一份工程里的署名。非空目录额外生成可读 `credits.txt`，进入 `build-info.json` 的大小/SHA-256 和离线缓存清单；制作交付包内的源工程和游戏一起携带。修改或清空名单后旧下载失效，重新生成生效。

## 边界与接续

名单是作品公开展示信息，填写不等于取得素材许可。本批使用明确标注的示例信息，没有替《雨停之前》编造作者、版权或授权。未实现滚动片尾演出、自动抽取素材许可、Markdown/HTML 排版或署名翻译；作者控制展示内容。

名单变化属于工程内容变化，按既有规则使试玩复核和旧版存档兼容核对过期；本批没有放宽兼容性或实现迁移。浏览器验证的是本地 HTTP、短工程及 Chromium 手机尺寸，未新增文件直开/离线下载完整链、其他引擎、物理手机、人工阅读听感、长路线、长期运行、素材授权或公网验收。1.5.4 原正文/素材与原候选保持，原长帧问题开放，Windows/Android 原生继续搁置。
