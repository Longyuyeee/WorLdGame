# Web 查找替换与整批撤销 · 2026-10-15

接续 `42a3d53`（#329）。本批处理校订长稿时统一称呼、错字和选项文案的任务，减少逐句进入编辑、应用和返回搜索的操作。

## 已完成

- 故事工作区增加“查找替换”，用独立弹窗收纳条件和修改预览。可选全部或某个场景，以及对白、旁白、选择提示/选项、结局名称；支持区分英文大小写。使用字面匹配，正则符号和替换文字中的 `$&` 等均按原文处理，不执行正则替换语义。
- 点击预览才计算结果。显示命中的文字条数、匹配处数、场景、类型和修改前后；每条替换其中全部匹配，可取消单条、全选或跨页保留选择，也能定位原文。长句先显示变化附近的片段，可展开完整文字。每页 12 条，最多预览 200 条；超过时要求缩小范围，不能对未展示的结果直接批量应用。
- 只改选中的文字字段。场景/角色名称、稳定 ID、表达式、演出参数和跳转目标继续使用原编辑入口。未应用文字或错误脚本草稿阻止打开/提交；改变查找条件或原文后，旧预览失效，需重新预览。替换为空可删除匹配部分，但结果整条为空、换行、过长或对白形成脚本标记时，整批拒绝。
- 每个场景仍走已有正式源事务，所有场景先在临时结果中完成并核对预览文字，全部成功才提交；任何一处失败，原工程与历史保持。应用后跨场景更新保存状态、增量检查和导出内容；弹窗打开时暂停编辑器试玩推进。
- 跨场景替换登记为同一批历史，在弹窗和现有顶部“撤销/重做”均一次处理整批。从涉及场景的对应历史位置操作；若某个场景已有后续修改或历史重建，明确列出阻塞场景，拒绝只恢复部分。普通单场景修改的历史继续保留。无关结构页面往返保留该批历史；正常保存重开保留文字，历史从新会话开始。
- 桌面用左右对照，手机改为上下对照、内部滚动和固定操作区；在手机点击预览后滚到结果，直接核对文字。桌面、390 px 浅深主题及实际导出 Player 截图已查看。
