## 作者从哪里使用

进入“游戏外观 → 其他页面”，先选择阅读菜单、存读档或剧情历史，再展开本页“自由组件与响应式布局”并启用。页面选择位于布局参数之前，不必滚过整组参数才能换页。

两组主组件分别承载原页面内容与标题／返回：菜单的推进、历史和进度操作；存读档的槽位、确认和备份；历史的查找与记录。它们以可见视口为边界，尊重顶部宿主栏和设备安全区，不套用剧情舞台比例。原关闭入口始终保留在返回组，内容可以独立滚动。

“编辑预览布局”继续使用正式 Player，支持选择、拖动、尺寸、方向键、取消和一次手势一次撤销；左右组件／设备选择同步。每页最多六个自定义文字、图片或功能按钮，保留九锚点、整数百分比、手机独立位置与显示设备设置。移动期间不操作真实游戏状态。内容与返回组冲突时使用安全布局，冲突的额外按钮进入可滚动的内容操作区，不挤占原关闭入口。

自由布局启用后，旧“本页宽度”“本页位置”和面板预设暂停使用并明确禁用，避免作者调整了却看不到效果。原圆角、字号、底色与背景素材仍沿用，内边距用于内容区，标题／返回区保持紧凑；关闭后恢复原模板。存档按内容区实际宽度切换单列，不只依据设备视口，桌面窄内容区也不会硬塞多列。恢复布局只影响所选页面，可撤销；不改剧情或删除素材。

## 玩家操作与进度保护

阅读菜单的自定义按钮允许返回、进入存读档、历史、设置、名单和附加内容，全部调用既有入口。存读档和历史页的自定义按钮只允许返回原页面，不开放直接覆盖、读档确认、历史跳转或任意脚本动作。

实际保存、读取、覆盖确认、类型／分页、备份导入和历史回退仍由原控件与服务处理。宿主不支持存储时，自定义存读档入口禁用；前台保存／备份忙碌时，额外返回按钮也禁用。未确认的读档可以用返回取消，不执行读取或修改手动槽位。

启用布局后的区域包装节点在测量和开关页面时保持稳定，改变窗口尺寸不会重建槽位确认、备份界面或历史输入。历史打开时聚焦原关闭按钮；关闭后返回实际触发入口，入口因菜单关闭而隐藏／移除时回到阅读菜单按钮。原菜单操作、键盘和存档原生 dialog 保持。

三页可选字段加入 `WebPlayerSkin.layout`，旧标题／阅读配置无需补字段；新字段仍严格校验页面、动作、数量、可见性和尺寸。所有页面图片共用素材引用与重新对应逻辑，包括只在桌面显示的图片。含新字段的皮肤需当前版本读取，不承诺旧应用可读。
