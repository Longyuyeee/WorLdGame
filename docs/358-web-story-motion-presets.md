## 作者现在能完成的任务

在“故事 → 写作”或“演出”选中对白、旁白或人物演出步骤，点击“动效预设 · 试看并应用”。效果先留在草稿，明确应用才改变剧情；失败保留参数，Escape 不会直接丢掉已改草稿。

| 作者任务 | 本批能力 |
| --- | --- |
| 人物入场与退场 | 柔和入场、轻步入场、渐隐退场；保留原有位置、缩放、旋转、锚点和层级 |
| 人物强调与呼吸 | 人物强调、轻柔呼吸、停止动效；在所选文字前插入当前场景已出场人物的演出，不猜测未知分支继承的人物 |
| 强调一句文字 | 墨色强调、文字轻提、停止动效；一次事务添加效果和恢复步骤，不把强调一直带入后文，也不替换 ADV / NVL / 气泡样式 |
| 看实际效果 | 使用正式 Player 的隔离片段预览，支持桌面、手机、放大与重播；始终静音，不写正式玩家存档、偏好或结局记录 |
| 调整与撤销 | 只显示相关的时长、强度、缓动和次数；重复调整同一句更新已有生成步骤，不堆叠动效；顶部撤销/重做可整体恢复该次剧情修改 |
| 跨场景或跨工程复用 | 命名后保存至工程，保存重开仍在；单个预设可导出、导入 `.worldmotion.json`，导入先进入草稿，不立即改剧情 |

时长限定 100–5000ms，强度 0.25–2，重复 1–8 次；入场和退场只播放一次。没有无限循环、闪烁、任意 CSS 或可执行脚本。预设库最多 32 项，同名覆盖使用明确的“更新同名工程预设”按钮。库更新属于工程设置，剧情撤销不撤回已保存的预设库；配置文件不携带人物图片或字体。

## 运行语义与修正

动效参数由 Story Core 的便携白名单定义，语言编辑、资源清单和正式 Compiler 拦截无效值。继续使用原 direction IR、Runtime 和 Host，不建立第二套剧情执行器，也不通过重复语句或等待拖慢阅读。

人物动效与基础 `transform` 分开，保持作者布局。渐隐退场的 hide cue 显式保留素材和几何参数；逻辑人物已经退场，画面只完成有限渐隐，减少动态效果或快进时直接隐藏。图片、Canvas 降级和文字节点离开时释放所拥有的动画。

文字使用 `@textbox action=motion`，Runtime 默认进入独立的 `textbox.motion` 通道，恢复步骤只改变动效，不覆盖已有对白框通道。保留旧 `@textbox action=set template=...`；普通新增对白框仍由原入口完成。尚无正文的场景也可预览人物动效。

系统减少动态效果、玩家减少动态效果和快进优先于剧情动画；暂停页面时暂停动画。高对比阅读不播放文字强调。隔离预览原本将音量置零，本批另统一显式 `muted` 属性和状态标识，避免状态与静音权限不一致。

首轮实际浏览器发现文字 motion action 未被 Runtime 接受，已修正并增加独立通道、NVL 保持及恢复回归。随后修正验证脚本中的四类问题：文本框焦点下的原生 Ctrl+Z 不等于顶部剧情撤销、HTML 格式值判断、场景名误当结局名、访问隐藏步骤按钮。五份原始失败报告及截图保留为 `failure-*.json/png`，没有算成通过。最终重新运行全部六组流程。

- 根类型检查、Editor / Player 生产构建、便携架构审计通过。构建仍提示大 chunk；jsdom 的媒体 load/pause 未实现提示不是实机声音验证。
- [六组真实静音浏览器任务通过](../evidence/web-motion-presets/browser-checks.json)：各人物动效试看/配置往返/应用；文字事务撤销重做；跨场景复用/保存重开；HTML 直接 `file://` 到达“有人等你回来”；HTTP `/gal/` 目录包在 **390×844** 到达“把明天写进信里”；系统减少动态效果仍可读。作者弹窗另核对 736 / 390 / 320px 无横向溢出。

独立 Player 结局合计 **2/2**，分布在 HTML 桌面一路和目录包手机一路，**不是每个格式与每条路线的全部组合**。编辑器本版本从头到结局仍 **0/2**，动效片段不计完整试玩。浏览器为桌面 Chromium 的手机尺寸，不计真机或 Safari。本批也没有验证任意旧档兼容、长时运行或改进长篇性能。
