## 本轮已经写入代码、尚未验收的部分

本轮处理准备背景、立绘和音频时反复逐个选择文件的问题，新增“批量导入素材”入口和独立弹窗。

1. 一次选择多文件，导入前核对文件、修改素材名称和用途，勾选要导入的项目。
2. 所选图片可统一设为背景、立绘、CG 或界面图片，音频、视频和字体不随图片用途改变。
3. 按顺序复用既有文件读取、媒体内容检查和素材保存流程，每项显示结果；普通失败后继续，失去写入资格等错误停止后续任务。
4. 支持停止和重试；已提交的成功项保留，重试跳过成功项。成功后可进入原素材详情。
5. 同名文件使用不同的新素材 ID，不静默覆盖旧素材。单文件管理入口继续承担主动替换。
6. 连续导入同步更新素材索引引用，下一项按最新索引保存；保留已有工程写入资格和版本检查。
7. 增加常见失败的中文说明、阶段提示及按钮在窄屏的排列样式。

### 当前实现边界

- 每批最多 50 个文件、合计 512 MiB；单文件沿用 64 MiB 上限。
- MIME／扩展名只用于建议用途，实际文件仍需通过既有媒体内容检查。
- 每项独立提交，整批不是一次原子事务；停止或失败不会撤销已经成功的素材。
- 文件引用、未完成队列和进度只在内存中，关闭弹窗或刷新后不能恢复；已导入的素材保留在工程中。
- 单元测试中的停止用例使用模拟的待完成导入；真实浏览器中的读取／检查阶段停止尚未确认。

## 恢复后按顺序做什么

### 1. 先收尾本轮批量素材流程

- 用真实浏览器选择混合图片／音频／坏文件，确认名称与用途编辑、同名新建、失败提示与重试不会重复已完成项。
- 确认真实停止／Escape、已完成项保留和继续未完成项；检查桌面、390 px、浅深主题、长列表滚动、底部操作区和关闭后的焦点。
- 按需补最后改动的类型／定向回归，只修复具体发现的问题。
- 将新素材用于背景、角色或声音演出，保存后返回首页／刷新重开，确认文件、名称、用途和演出均保留。
- 导出实际目录／制作包，检查新素材进入产物，再用独立 Player 确认背景／声音和到达结局。
- 记录实际通过、失败和未跑项后，才将 #331 标记为完成。

### 2. 继续完整 Web 作品定稿

- 使用真实作品持续创作和校订，优先处理实际操作的阻塞、自然阅读、对白与演出衔接、音乐／语音听感和内容收尾。
- 完整走主要分支、结局、收藏／回想、保存刷新读取及恢复流程，避免用局部短工程代替作品验收。
- 确认真实手机和支持的浏览器体验；处理实际卡顿、媒体失败和恢复问题。历史长帧问题仍开放，本轮未验证改善。
- 完成作品素材来源与许可、作者／发行署名和展示资料核对；不替用户编造署名或认定授权。
- 交付最终可编辑工程与可部署游戏包、说明和已知限制，并完成实际部署环境的最终回查。具体发布平台目前不作为开发前置问题。
