## 当前实现与审计边界

至少 480 条、主线最新游标、正在呈现正文且无回想时，Auto／已读快进／全部快进使用现有前台计算通道的独立 `playback` 任务。仍调用公开 `schedulePlayerCorePlaybackV1`，每次完整校验历史和调度器；没有历史截短、已验证缓存或另一套 Shell 调度器。短篇、记录未来、回想、作者预览及媒体等待输入保持原路径，不把它们算作本批异步覆盖。审计专门区分“允许当前播放”和“启用后台计算”，防止不使用 Worker 的作者预览被误吞计时回调。

Auto 仍先等文字显示、读完本段、画面就绪，以及真实语音 ended／失败和尾部时钟，再发起一次计算。权限拒绝不是语音结束；重试或恢复的语音是新归属。Worker 不操作音视频、计时器或存储，返回效果仍由原 Host 与实际媒体元素执行。视频等待／取消策略不变，选择、结局、未读、指定停止点和预算仍由 Runtime 判定。

前台只持有一个待提交批次，不排队累积过期的 Auto 时钟或按住输入。源状态、通道、播放参数、阅读节奏及语音归属都必须仍匹配才能提交。停止、正文点击／键盘接管、松开按住快进、菜单／存读档、后台、内存保护及卸载作废旧结果；返回 Auto 使用新的等待，不采用旧回复。跨窗口已读知识更新即使没有移动游标，也会取消旧批次，并让仍激活的快进从新的完整源继续，避免“快进中”却没有后续计算。计算期间主动点击正文先停止留在当前句，不在主线程重复长篇计算，下一次手动继续沿普通路径。

失败会停止 Auto／Skip、保留当前句和原存档并给出说明，不自动在主线程重算或循环重试。用户可切回手动，也可明确重开播放。计算提示优先于上一条存读档通知，旧通知清除；菜单等面板不被错误层覆盖。320px 停止入口与正文的实际可见范围由浏览器截图核对，不仅做 DOM 存在断言。

## 调度器与完整传输

沿用独立完整的输入／结果编码包，增加同包 Scheduler 的历史和 workingState 编码。Scheduler 与根历史的**对象归属**必须保持：共享历史还原为同一对象，不共享的历史即使值相同也不合并。临时 workingState、累计指令、未读／预算停止状态、主历史、所有中途保存候选和回想入口均保留。预算内可能不增加历史游标，不能套用普通单句“必须前进”的回复判断，也不能丢掉调度器从头重跑。

列表表与展开预算继续由共享编解码器约束，超预算发送完整普通数据，损坏编码拒绝；不放宽 Runtime 容量、验证或存档兼容。传输仅存在于同一构建的私有计算通道，不写入工程、数据库或存档；没有跨版本复用旧包的协议承诺。前台和恢复仍至多两个计算通道，取消／卸载释放对应资源。

下表均为“基线 → 当前”。长任务为整个工具操作窗口内 ≥50ms 的主线程任务，不是 Worker CPU；总等待含菜单、自动化输入、时钟、轮询与帧回调，不能当成纯计算或真实设备点击延迟。

| 480 已读 | 3 → 0 | 82 → 0 | 212.2 → 207.8 |
| 480 全部 | 3 → 0 | 71 → 0 | 197.1 → 213.7 |

本批价值是可响应、可取消和不重复执行，**不是总等待全面提速**：六组中五组总等待更长，480 已读略短也不能泛化。480 条采样的长任务消失；960 条仍有七个长任务。时间戳显示其中三个在计算回复前，另四个在首次正文帧回调后，没有落在回复到该帧的窗口内；这不是 CPU 归因，剩余来源仍待单独剖析。960 条回复到所观察帧约 6.5–27.2ms，仅是 rAF 观察，不代表物理呈现。原生发送中位数 480 为 2.0–3.2ms、960 为 3.5–4.4ms，不含发送前编码，不能代表整体复制或总 CPU。

十八批正文／游标／完整历史长度／Runtime hash／停止原因逐项相同，两档原快速槽规范字节长度、SHA、Session artifact hash 和 Runtime hash 相同；原快速槽没有因播放被覆盖。新增结果的逐批完整对象、全部中途候选及规范存档一致性由纯函数往返测试覆盖，不把原快速槽摘要冒充所有新结果的原生字节检查。读档合并已读知识遵循原单调规则：可以回到旧句而 live hash 合法变化，不为比较强制回退已读／解锁。

固定顺序、每档三次、同一桌面 Chromium 的样本不等于总体提速、所有硬件容量、物理手机或长期稳定性通过。最终可重建 bundle／夹具／冻结源／CSS 摘要核对后才对应本批提交；没有把开发中的旧报告当最终代码证据。
