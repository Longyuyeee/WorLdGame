## 用户操作障碍与修复

1. 更换已有演出原来要求输入 Asset ID，无法直接辨认素材。改为按显示名称选择，提供实际图片预览/音频主动试听；技术 ID 收起保留，缺失或不兼容旧引用仍明确显示，不偷偷代换资源。
2. 演出参数离开前没有草稿保护。现在更改后阻断场景/步骤、主要任务、保存/导出和撤销，只有应用或明确放弃才离开；应用失败保留草稿与错误。最终审阅还补上高级设置内的旧视图禁用与切换回调防护，避免绕过主入口丢稿；新增 App 回归，并在 320 实际高级入口复查。参数表自身不因脏状态自锁。文案区分文字自动提交与演出手动应用，避免“失焦会应用”的误导。沿用同一源事务与撤销/重做，不新增第二份剧情权威。
3. 插入与更改的音量接受规则不同。共同采用 0–1/千分精度规范化，`.3`/`1e-3` 等变成源格式；超精度阻断提交。已有参数留空可移除覆盖，新增音频仍要求明确合法音量；事务拒绝不清空输入。
4. 320 阅读首段时立绘脸部仍被正文压住，窄屏竖屏缩短舞台世界下沿，让常规首段脸部处于文字框上方。不修改作者的 x/y/scale 或 Runtime 几何；超长文字/任意站位不承诺始终能同时显示整个人物。
5. 初次完整路线检查通过，但目视 HTTP 画室截图发现存档按钮盖住正文。原检查只约束舞台/视口，遗漏目录外部的离线/版本栏和固定操作区。目录页初始化/折叠展开/窗口缩放及状态换行均按真实栏高更新 viewport offset（ResizeObserver + toggle/resize，初始化在 file/原生协议早退前）；无脚本默认预算 68px。移动历史/播放等面板避开宿主栏，文字和存档各留独立位置。后续完整路线每段都检查上下操作不重叠；旧问题截图 `review-before-directory-overlap.png` 保留，不算通过证据。

制作脚本早期遇到输出目录未建、语法多括号、嵌套 summary 非唯一、保存按钮旧名称，以及 dirty effect 未稳定前即时断言；组件测试也曾用错主资源名称。分别修正日志目录、语法、直接子 summary、当前保存入口和等待真实禁用状态；这些工具失败未当成产品通过。`failure.png` 是早期脚本同步检查失败快照，非最终界面截图。jsdom 未实现媒体日志仍不当作实际音频播放证明。

高级视图回归初次误用 Playwright 的 `exact` 选项，TypeScript 拒绝后移除，重新 typecheck/构建通过。该补丁只影响 Editor 切换保护；未改变已走完路线的 Player/导出代码或正式产物，随后复跑当前界面四项回查和 245 项定向回归，不冒称又跑了一遍完整制作全链。
