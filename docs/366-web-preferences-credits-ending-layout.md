# 366 设置名单与结局的布局编辑

2026-10-17，接续 [#365](365-web-menu-save-history-layout.md)与 [#357](357-web-development-handoff.md)第四项，完成玩家设置、制作名单和结局页的自由布局制作流程。作者可在正式 Player 预览中调整内容与返回区，分别制作桌面和手机排版，保存重开、携带素材复用，并导出独立 HTML 与目录游戏。

本批继续服务于 [#304 Web 完整 Gal 的制作与交付](304-web-complete-gal-delivery.md)，没有另建剧情、存档或收藏系统。《给明天的回信》0.8.0 保留 0.7.0 的剧情、角色、七份素材，以及标题、阅读、菜单、存档、历史的布局；新增的是三页的作者布局能力，不是新增完整剧情或正式发行完成。0.7.0 和既有《雨停之前》1.7.14 继续保留。

## 作者如何制作

进入“游戏外观 → 其他页面”，选择玩家设置、制作名单或结局画面，展开本页“自由组件与响应式布局”。启用后分别调整两组主组件：设置项／设置标题与返回，名单正文／名单标题与返回，结局信息及收藏读档／返回标题或原剧情。

三页以可见视口为边界，不把功能页挤进剧情舞台比例。沿用真实画布的选择、拖动、尺寸、键盘微调、冲突定位、一次手势一次撤销；每页最多六个文字、图片或有限功能按钮。手机可以独立设置位置和尺寸，或采用安全布局；图片可仅在桌面显示。内容独立滚动，原返回入口保留，冲突的额外按钮并入内容区。

自由布局启用时，旧窗体宽度、位置、面板预设和整页入场动效暂停使用，界面明确禁用，避免调整无效参数。圆角、文字大小、底色、背景素材及内容内边距继续生效；返回区保持紧凑。关闭自由布局可恢复原模板，恢复单页布局可撤销，不改变其他页面或删除素材。

制作名单和结局的窄内容区按自身宽度收为单列，不只按整个浏览器宽度判断。名单的较长来源说明可以一直读到末尾，返回入口不随正文滚走。样章采用桌面左侧内容／右侧插画与额外返回、手机全宽内容的验证排版，不作为最终美术定稿。

## 玩家操作与进度保护

设置页继续使用原个人字号、文字显示、逐字速度、各声道音量、静音、无障碍、全屏和恢复默认控件。修改即时应用，只影响玩家个人设置；返回不会推进剧情，重开仍按原机制恢复偏好。布局测量和窗口切换不重建设置输入或名单正文，保留焦点、参数和原触发入口的返回逻辑。

名单继续读取原署名、网站、制作人员与来源文字，链接沿用校验与 `noopener noreferrer`，不新增任意链接或执行动作。三页的自定义按钮仅允许返回；不允许直接修改偏好、清空收藏、确认读取或执行脚本。

结局页保留原结局名称、达成数量、收藏与结局入口、制作名单、确认读档和原返回按钮。额外返回调用同一重启入口；回想结束时改显示“返回原剧情”，调用退出回想，恢复父剧情的状态摘要、宿主快照摘要和历史游标，而不是重启父剧情。回想不显示普通结局收藏／读档操作。前台保存忙碌或宿主暂停时不允许额外操作；子页打开时结局控件不可交互。

三个新布局字段是可选项，旧标题／阅读或前三页的配置无需补字段。新页仍严格校验动作、组件数量、显示设备、整数坐标和尺寸；图片沿用统一引用、皮肤打包、重新对应及缺图回退。含新字段的配置需当前版本读取，不承诺旧应用可读。

## 实查问题与修正

真实预览发现设置页仍受旧模板的居中宽度限制，实际内容与编辑框错位。已把视口布局样式放在旧模板之后加载，并增强根布局规则，保留失败 `failure-2026-10-16T19-40-18-162Z.*`。最终逐页核对桌面／手机编辑框与内容区，容差为 1.5px。

正式 HTML 的结局页还曾遮住收藏子页，返回按钮虽然存在却点不到。结局进入收藏时现保持节点和状态、隐藏底层布局，并设为不可交互；关闭后恢复原结局。手机结局自由布局也不再叠加阅读工具条，以免占用返回区。两格式均实际点击收藏返回、名单返回、取消读取和确认读取后接续；原遮挡失败 `failure-2026-10-16T19-43-34-055Z.*` 保留。

另外两次测试脚本失败分别来自把高对比模式主动隐藏的装饰算作可见项、误用原设置按钮的可访问名称，已修正测试条件，原失败文件保留，未计入通过。截图等待有限的页面入场动画完成，避免把透明首帧当作最终画面。

## 本批验证结果

[235 项相关回归、36 文件通过](../evidence/web-info-ending-layout/unit-tests.json)，覆盖六个可选页面、旧配置往返、动作拒绝、图片引用与缺失回退、作者撤销、手机安全区、设置参数与焦点、名单链接、结局与回想返回、原存档确认、收藏、阅读及导出。根类型检查、Editor／Player 生产构建和 118 个便携文件、4 个 Node 适配文件架构审计通过。jsdom 不提供真实媒体播放；生产构建仍有大 chunk 提示。

[五组实际静音浏览器流程通过](../evidence/web-info-ending-layout/browser-checks.json)：

1. 在主样章逐页制作三页布局，调整桌面／手机，实际拖动在松开后提交，一次撤销恢复，方向键微调，核对真实预览几何与安全动作列表。
2. 应用、保存、返回项目列表并重开；导出工程、皮肤配置、带素材皮肤、HTML 和目录包。双游戏外观等于工程，剧情、角色、素材及既有五页布局等于 0.7.0，正式游戏没有编辑预览标记。
3. 独立桌面 HTML `file://`：个人字号、音量、高对比、恢复默认、重开偏好；标题及结局名单返回；保存首句、完整第一路线、结局收藏、取消读取、明确确认读取回到原句、原返回与额外返回。
4. 独立触屏目录 HTTP：390×844、844×390、390×480 下三页参数与正文保持、原返回按钮在视口内；完成另一条路线，并实际使用结局的收藏、名单、读档与两种返回。独立存储内各达成一条，合计两结局 **2/2**，不是全格式×路线矩阵。
5. 第二个空白工程导入带素材皮肤，三页布局与桌面专属图片可复用，原脚本和角色文件逐字节不变，名单页真实预览仍可编辑。

目录 18 个文件的大小与摘要核验通过。编辑器整部路线未重跑；触屏、横屏与短视口来自桌面 Chromium 151，不替代物理手机、Safari、系统键盘或自然阅读／听感验收。
