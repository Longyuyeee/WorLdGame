## 本轮改动

- 读档后台输入改为明确的 `PlayerCoreSessionLoadSourceV1`：故事程序、构建身份、已核对旧版、当前 Meta Progress、回想入口和诊断。正在被替换的整份历史、运行现场、Host、调度队列、检查点前缀，以及无关素材/本地化目录不再跨线程复制。
- `preparePlayerCoreSessionLoadV1` 每次仍调用完整公开 Runtime 加载器，核对完整历史、构建、存档边界和单调收藏合并，重建演出及回想。公开完整 Core 加载接口与无 Worker/CSP 回退使用同一实现。需要续行的检查点仍经过正式推进；候选保存前缀在加载结束时清空。
- Worker 只返回加载后的动态字段。主线程核对项目/构建、历史长度/游标、返回类型和候选清空等，再逐字段合并，保留当前工程的 artifacts、本地化、策略和兼容表引用。超时、取消、坏回复、旧队列及内存保护释放规则沿用 #351；没有缓存验证结论或删减加载历史。
- 标题页“继续最近存档”等待时显示校验提示，开始故事、其他标题操作和语言选择暂停，Enter/空格不能在读档中另开故事。隐藏不可执行的开始快捷键提示，禁用按钮有明确淡化状态。成功直接回到故事；失败打开现有错误面板，关闭后可正常开始。
- 保留“恢复记录扫描尚未结束时，主动读取正式槽位可取代旧扫描”的既有流程。
- 实际检查 844×390 截图后，补上标题面板的视口内滚动和不可压缩的内容项，避免标题与底部操作裁切；三种尺寸实走滚动到底部操作，再返回读取提示。
