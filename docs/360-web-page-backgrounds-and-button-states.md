# 360 页面背景与按钮状态素材

2026-10-17，接续 [#359](359-web-skin-bundles-and-repair.md) 与 [#357](357-web-development-handoff.md) 第二项。作者现在可以给九个页面分别选择背景图片，为操作按钮选择四种状态底图；这些配置与素材贯通正式预览、皮肤包、另一工程、保存重开和双格式游戏。目标仍是 Web 完整 Gal 制作，没有恢复原生开发，也没有将功能验证小工程当成完整作品定稿。

## 作者现在可以做什么

在“游戏外观”的标题、阅读、其他页面中，选择“本页背景图片”，调整铺满裁切或完整显示及不透明度。九个页面分别保存：标题、阅读舞台、阅读菜单、存读档、剧情历史、玩家设置、附加内容、制作名单、结局。调整一页不会替换其他页；移除背景可以恢复原底色/封面行为。

阅读舞台底图位于剧情画面后方，不替换演出中的场景背景；其他页面使用各自窗体的背景，内容和操作仍在前方。降低图片不透明度会增加窗体颜色的衬底。背景尺寸与演出画幅没有绑定，不会为填满手机而改变剧情构图。

“皮肤与动效”提供普通、悬停与键盘焦点、按下、禁用四张按钮底图，以及就近的图片按钮文字颜色。文字颜色与原“主按钮文字”共用；没有选择的状态沿用普通图片，普通图片也没有选择时使用原底色。此时图片按按钮大小拉伸，**九宫格尚未提供**，应使用适合拉伸的底图。

按钮底图仅用于操作按钮，不套到对白推进区、历史正文条目或画廊图片。玩家高对比阅读优先隐藏装饰图片并保持黑底白字；减少动效、按钮原动作和键盘焦点保留。手机按下反馈不依赖悬停。

以上调整沿用外观草稿、撤销/重做、应用和正常工程保存流程。旁边的“导入背景与按钮素材”进入现有素材管理，不要求手输内部标识。

## 素材复用与兼容

- `WebPlayerSkin.images` 为可选字段，旧工程和旧皮肤无需补字段；新字段只接受已知页面、合法素材标识、适配枚举和有限不透明度，不接收 CSS 或外部 URL。
- `webPlayerSkinReferences` 和共享映射函数统一处理对白窗体、页面图片、按钮图片和字体。配置 JSON、带素材 ZIP、缺失回退和真实预览使用同一组引用，不另设预览协议。
- `.worldskin.json` / `.worldskin.zip` 仍使用现有格式；新增图片字段需要当前版本应用读取。图片保留已检查 PNG/JPEG/WebP、8 MB / 400 万像素限制；字体仍为 32 MB，整包素材仍为 64 MB。
- 原 8 项上限不足以容纳整套页面，配置、ZIP 清单、来源记录和整批新增事务上限统一扩到 **24 项**。包内摘要、路径、来源隐私、writer lease、旧索引拒绝和整批回滚继续生效。
- 未提供或加载失败的装饰图片不会阻止阅读与按钮动作；导入检查仍要求明确补齐、对应或回退。公开许可合并，内部台账默认不分享，不将原工程的授权确认当作目标工程已审查。

## 发现并修复的问题

触屏环境中，仅依赖 CSS `:active` 不能可靠显示按下图。现在只为装饰反馈监听指针/键盘事件；松开、滑动超过阈值、取消、离开、滚动、失焦、隐藏或卸载时清除状态，不拦截点击、不捕获指针，也不更改剧情状态。[修复前诊断](../evidence/web-skin-images/touch-diagnostic.json)保留；最终目录游戏用真实浏览器触点按下/松开核对底图切换。

截图审查还发现对白推进区实际上是原生按钮，会被过宽选择器套用操作按钮底图。已将对白和历史正文条目排除，并增加真实 Player 检查与事件测试。[修复前画面](../evidence/web-skin-images/dialogue-before-fix.png)与[修复后手机阅读](../evidence/web-skin-images/game-phone-reading.png)可对照。图片按钮增加就近文字颜色入口，避免不同底图上的文字不清楚。

四份 `failure-*.json/png` 保留：前两次为脚本返回按钮名称与重复定位问题，第三次为目录相对 URL 与计算后绝对 URL 的比较问题，第四次暴露上述触屏反馈缺陷。它们不计入最终通过。

## 实际工程与验证结果

保留《给明天的回信》0.4.0 与 #359 的原产物，不重发。使用隔离副本从真实界面导入 **13 张程序生成的色块/线条 PNG 测试图**，配置九页背景与四种按钮状态，再导出皮肤并导入新建“页面素材复用验证”**0.1.0**。新工程含三段新旁白、一个结局，皮肤所需封面、字体和新图片共 **15 项素材**。这些程序测试图不代表最终美术或发行授权。

实际源包与两种游戏的外观一致，两种游戏包含同一工程且没有编辑器预览模式。15 项源素材和目录清单 **26 个文件**核对摘要，目录文件大小通过；实际下载文件的大小与 SHA-256 记录在浏览器报告。

本批为功能小工程验证，不增加原 0.4.0 路线覆盖，编辑器整部试玩未新增。桌面 Chromium 和触屏模拟视口不等于真机/Safari；完整篇幅、人工自然阅读/听感、任意素材发行条件、公网交付和长篇性能仍保持原边界。
