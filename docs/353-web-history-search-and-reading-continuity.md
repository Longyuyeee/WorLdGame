## 用户流程

- 剧情历史可查找主线和只读归档，支持中文、Ruby 正文/注音、全半角和大小写等价文字；显示匹配数量和空结果。查找只读取展示快照，不改变剧情或完整历史。每组仍最多呈现 40 行，清除后定位当前句，清除按钮保持输入焦点；第一次 Esc 清除关键词，空关键词时再 Esc 关闭面板。
- 修复已有的“回退到旧句后，点击正文继续会进入 Runtime 错误”的问题。Core 的普通推进在存在记录未来时使用正式 Forward，经过原 Host 演出协调并遵守 `allowForwardAfterBack`；不覆写未来、不生成重复分支，也不放开禁止前进的作品设置。
- 真实归档查找检查发现内存保护提示挡住阅读菜单按钮。打开菜单/历史/保存/设置/附加内容或欣赏画面时暂时收起提示，回到正文继续显示，保护状态和重试能力保持。
- UTF-8 编码在可用宿主上使用原生 TextEncoder，仍在编码前严格检查 NFC 与完整代理对，继续拒绝不可规范化输入；缺失或受限宿主保留原来的便携编码器。跨 JS realm 的输出用当前 realm 的 Uint8Array 视图包裹，不复制字节。无缓存历史、哈希或验证结果。
- 同时试验过 SHA 压缩环节的有符号整数运算，采样没有明显收益，已撤回源代码和该实验专用测试；最终不改 SHA 算法/格式。实验源码和数据保留在 `experimental-sha256.txt` / `experimental-long-current.json`。
