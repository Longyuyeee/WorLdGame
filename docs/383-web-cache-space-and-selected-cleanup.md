# 383 缓存空间与选择清理

2026-10-17，完成 [#382](382-web-content-update-and-old-version-continuity.md) 第一项接续任务。玩家能查看本游戏保留的版本、缓存文件内容大小和使用状态，备份后只清理不再使用的版本。仍为《雨停之前》**1.9.0 内容候选**、技术基线 S0.41，原剧情、素材与存档兼容范围不变；继续服务 [#304 Web 完整作品交付](304-web-complete-gal-delivery.md)。

## 玩家操作与保护范围

标题或阅读菜单的“离线与安装”增加“查看缓存与空间”。列表显示发布版本与构建短标识，同为 1.9.0 的两个构建可以区分；每份缓存显示文件数、内容大小和是否齐全。大小来自实际缓存响应的内容字节，**不含存档、内部缓存元数据和浏览器索引／压缩开销，不等于磁盘占用**。无法读取大小时显示未知，不当成零。

当前窗口、本机默认版本和其他窗口正在使用的版本不能清理。下载、修复或等待启用新版时暂缓清理；版本元数据缺失／损坏、存在无法识别版本的游戏窗口时也不允许冒险删除。默认版本保留用于正常启动与离线，不提供“一键清空站点数据”。

玩家可从此处直达原备份页。选择闲置版本后，确认区明确说明该版入口会失效、当前服务器可能不再提供原版、操作不能撤销；需要勾选已保留需要的原版游戏与进度备份，再确认清理。取消不改缓存，焦点返回所选版本。确认提交后禁止重复提交或假装还能取消；玩家仍可收起管理、返回游戏，完成时不抢走已移至其他页面的焦点。

清理只移除所选游戏版本的 CacheStorage 项，不删除存档槽位、缩略图或已导出的文件。实际磁盘空间何时回收由浏览器决定。旧版入口清理后明确报告不可用，不自动改开新剧情；`.worldsave` 本身不能替代原版完整游戏文件。

## 确认时重新核对

实现集中在 [web-offline-export.ts](../apps/editor/src/web-offline-export.ts)，没有改 Runtime、Player 存档协议或另建剧情解释器。缓存读取与删除只接受本游戏 scope 内的请求，只操作精确 scope 前缀和完整 SHA256 构建标识；其他应用／路径的缓存不进入清理目标。

Worker 在确认时及读取元数据后再次核对窗口和更新状态，因此列表打开后重新出现的旧窗口也会阻止清理。缓存列表读取、游戏文件请求与清理互相保护，避免并发删除后又把旧缓存重建为空项；清理中的请求不取新版文件补齐旧版。界面区分已确认删除、被阻止和无法确认结果，清理成功后即使刷新列表失败，也保留成功结果，不误报“未执行清理”。

旧元数据不足时采用保守保护，不猜测版本或自动删除。历史 UI 不能自动获得新管理按钮，需使用当前导出游戏并完成离线组件更新；尚未支持管理的组件读取失败时给出重试说明，不绕过 Worker 直接清理浏览器数据。
