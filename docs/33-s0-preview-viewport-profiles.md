## 1. 需求对齐

用户确认当前 UI 视觉格式可以继续沿用，但要求更多生产功能逐步体现在界面中，并明确右侧预览默认 16:9、其他尺寸可调整。

S0.14 冻结以下边界：

- 保留现有现代、极简、多彩、平滑动效的导演台布局；
- Preview 默认使用 1920×1080 / 16:9；
- 提供 16:9、16:10、4:3、21:9、9:16 五个常用生产 Profile；
- 提供 240–8192 范围的自定义宽高和约分后的实时比例；
- 切换尺寸只改变编辑器预览工具状态，不修改剧情、不产生 source revision、不触发自动保存；
- 横屏画布填充可用宽度，竖屏画布保持真实比例并限制宽度，避免被右栏强行拉伸；
- 当前切片不把 Preview Profile 写入项目 schema。正式设计分辨率属于后续 Project Settings，并需要平台覆盖和迁移策略。

## 2. Profile 契约

| ID | 名称 | 设计尺寸 | 比例 |
|---|---|---:|---:|
| `landscape-16-9` | 标准横屏 | 1920×1080 | 16:9，默认 |
| `desktop-16-10` | 桌面宽屏 | 1920×1200 | 16:10 |
| `classic-4-3` | 经典画幅 | 1440×1080 | 4:3 |
| `cinema-21-9` | 超宽银幕 | 2560×1080 | 21:9 |
| `portrait-9-16` | 手机竖屏 | 1080×1920 | 9:16 |
| `custom` | 自定义 | 240–8192 | 自动约分 |

Profile 定义位于独立的 `preview-viewport` 模块。ID、标签与尺寸有纯单元测试；未知或已移除 ID 安全回退到默认 16:9。自定义输入被规范为安全整数并限制范围，`1920×1080` 显示 `16:9`，`1000×1000` 显示 `1:1`。

## 3. UI 与数据边界

右侧 `LIVE PREVIEW` 标题下新增可访问的“预览尺寸”选择器。舞台标题同时显示当前比例，工具栏显示设计像素；自定义模式显示宽、高和实际比例。

画布通过 CSS `aspect-ratio` 使用真实宽高，而不是仅替换标签。棋盘底板负责表达画布之外的工作区；竖屏 Profile 在桌面和手机端均限制为 240px 宽，防止右侧栏被纵向画布撑破。

尺寸状态保存在 `PreviewPanel` 的 React 会话状态中，不进入 `StudioSession`、`StoryProject`、ProjectSnapshot 或 WAL。这保证它不会伪造故事变更，也为后续“项目设计分辨率”和“本机预览偏好”分离保留空间。

## 4. 功能呈现顺序

“更多功能体现”按真实能力递进，不增加无行为占位按钮：

1. **S0.15 Preview Transport**：0.5×/1×/2×/4×/无限速、自动推进、Step Back/Forward 的明确状态机与停止点；
2. **内容寻址资源索引**：为 CG、音频、缩略图、差分切图和迁移建立可靠 Blob 契约；
3. **自动内容中心**：路线图继续从故事模型派生，画廊/回想/音乐/结局从资源与解锁引用生成；
4. **Project Settings**：设计分辨率、方向、安全区、平台覆盖、预览/测试/正式 Profile；
5. **生产 QA**：从任意语句运行、变量/调用栈、视觉对比、资源收益与构建报告。

## 5. 自动化与真实浏览器证据

自动化覆盖：

- 默认 Profile 是 1920×1080 / 16:9；
- 五个预设的 ID、标签、尺寸和方向唯一且有效；
- 未知 Profile 回退默认值；
- 自定义尺寸限制与比例约分；
- UI 切换 16:9 → 9:16 → 自定义 1:1；
- 切换后 source revision 保持 r0，没有故事编辑副作用。
