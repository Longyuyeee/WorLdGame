# S0.39 演出轨道 64 步渲染窗口审计

## 阶段目标

S0.39 解决长场景中四条演出轨道和剧情卡片随步骤数线性扩张 DOM 的问题。Writer 现在使用一个固定最多 64 步的确定性窗口，同时驱动 BG/CHAR/AUDIO/STORY 四轨和下方剧情卡片；完整场景、选择、预检、Preview 与权威脚本仍保留全部步骤，不因 DOM 卸载丢失状态。

本阶段不引入第三方虚拟列表、不改变 source command、不增加跨窗口拖放，也不修改 project schema。

## 冻结窗口契约

### 确定性分页

- 默认窗口大小为 64，起点始终对齐到 64 的稳定页边界。
- 起点小于 0、超过末页或窗口大小非法时采用明确钳制/默认规则，不产生负区间。
- 末页可以少于 64 步；窗口的 `end` 使用半开区间并且永不超过场景总数。
- 上一段/下一段每次移动一个完整窗口，按钮常驻 DOM；手动翻页后键盘焦点不会因为 Cue 卸载而失去到页面主体。

### 当前步骤定位

- 当前选中步骤变化且落在窗口外时，窗口自动切换到包含该步骤的页面。
- 手动翻页允许暂时查看不含当前步骤的页面，“定位当前”可显式返回。
- 切换场景时先清理临时多选并把窗口重置到新场景当前步骤所在页面。
- 窗口状态仅属于 Writer 会话，不进入项目快照、WAL 或 Undo。

### 共享 DOM 上限

- 四条轨道只遍历 `visibleStatements`；每条轨道为窗口内非本轨 Cue 保留占位，保证同一时间列继续对齐。
- 剧情卡片使用完全相同的 `visibleStatements`，不会在轨道窗口化后继续渲染完整 10,000 步列表。
- 轨道暴露 `data-window-size` 与 `data-rendered-statements`，便于自动化直接检查上限，而不是只依赖视觉推断。
- 可访问名称明确宣告当前显示的首尾步骤和场景总数；窗口状态使用 `aria-live=polite`。

## 选择、拖放与焦点边界

- 多选 ID、范围锚点、整轨选择和批量预检继续基于完整场景投影；窗口外 Cue 被卸载不等于取消选择。
- 拖放只接受当前窗口中仍挂载的目标；拖动期间翻页按钮锁定，避免源 Cue 在手势中被卸载。
- 跨窗口重排继续使用稳定 ID 左右移动命令；自动跨页拖动需要单独冻结边缘滚动、占位和取消语义。
- 翻页按钮、窗口状态和“定位当前”始终挂载；手机端按钮至少 44 px，并把定位按钮放到独立整行。

## 纯函数

`stage-window.ts` 提供三个无副作用入口：

- `createStageWindow`：规范化总数、请求起点和窗口大小。
- `moveStageWindow`：按稳定页大小前后移动并钳制到合法边界。
- `revealStageIndex`：只在目标位于窗口外时计算新页面；窗口内定位保持对象不变。

React 只保存 `stageWindowStart`，其余边界全部由纯函数派生，避免总数变化后保留非法末页。

## 审计结论

1. 轨道和剧情卡片已消除完整场景 DOM 的双重线性增长，单窗口最多处理 64 个步骤。
2. 数据层仍完整：选择、参数预检、Preview 和 source transaction 不读取可见 DOM。
3. 翻页、定位和场景切换不创建 revision；窗口不是作品内容。
4. 拖放不会在手势进行中切换页面，避免卸载源节点和丢失 DataTransfer 状态。
5. 当前计算成本已远低于预算；下一生产瓶颈是 10k 场景中的直接跳转与搜索发现性，而不是窗口边界计算。

## 验证证据

- `npm run check`：47 个测试文件、310 项测试、TypeScript、生产构建、34 个可移植文件 / 3 个 Node adapter 架构边界，以及脚本和资源性能门全部通过。
- 10,000 步中以 17 步间隔执行定位并混合整页移动共 0.24 ms，冻结预算 100 ms；末页规范化为 `9984–10000`，最大渲染步骤保持 64。
- 10,000 Cue 整轨/范围选择 1.98 ms；256 条 Directive 预检 3.96 ms、原子 Patch 294.65 ms，证明窗口层没有破坏既有生产性能门。
- UI 回归直接断言轨道 `data-window-size=64`，并确认轨道与剧情列表共享 `1–4 / 4` 窗口、翻页/定位禁用边界和帮助文案。
- 真实 Chromium 验证：已恢复的 6 步场景报告窗口 64、实际渲染 6，完整 BG 轨选择 3 条且 revision 不变；切换到 3 步场景后窗口重置为 `1–3 / 3`；Preview 仍为 1920×1080、16:9 Balanced。

## 下一阶段入口
