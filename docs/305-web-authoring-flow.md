## 实施前交互设计

| 用户任务 | 入口与交互 | 成功反馈 | 失败或放弃 |
| --- | --- | --- | --- |
| 写作时需要新角色 | 故事工具栏“添加”；缺角色提示直接提供创建入口。角色弹窗先显示名称和颜色，立绘槽位/默认表情收在高级选项 | 创建后回到原场景，角色可立即用于对白 | 当前输入先保存；保存失败留在编辑器；弹窗内显示无效值，保留输入 |
| 增加剧情场景 | 故事工具栏“添加场景”，填写名称和所属章节 | 创建后直接进入新场景写作 | 取消回到原场景；不改变游戏入口 |
| 记录好感度等状态 | 故事工具栏“添加变量”；缺变量提示提供入口。使用中文类型与作用范围说明 | 创建后回到原场景，变量可用于赋值/条件 | 无效默认值保留弹窗与提示 |
| 管理较多内容 | 独立章节/角色/变量页面只展示名称、数量、摘要与操作；编辑字段进入弹窗 | 章节中可直接进入具体场景；修改有清晰保存状态 | 编辑草稿阻断无意关闭；明确放弃可关闭；保存期间阻断重复操作 |
| 删除被引用实体 | 确认弹窗展示影响与替代对象 | 迁移引用与删除使用同一事务，可撤销 | 未选替代对象不能继续；包含场景的章节先处理场景 |

默认界面隐藏技术 ID；需要时在技术信息中查看。创建、编辑与确认同一时刻只显示一个有焦点的弹窗。手机继续使用单列列表和大触摸目标。

## 实施与验证顺序

1. 调整结构管理列表与弹窗；保留实体引用、事务、撤销重做与保存能力。
2. 接入写作中的直接创建入口与当前场景返回。
3. 使用真实浏览器从空白工程创建自己的分支短篇，通过编辑器完成两个结局、保存重开与 Web 导出。
4. 查看实际界面截图、检查窄屏与弹窗焦点；只运行涉及本包行为的必要回归、类型与构建。
5. 在本文件末尾记录完成内容、实际结果、未运行项与剩余问题。完整作品长度、真实部署及性能包继续按 #304 后续推进。

## 本包完成记录

已实现写作中的“添加内容”和缺角色/变量时的直接创建入口。角色、场景、章节、变量改为摘要列表与原生弹窗；角色高级字段、技术 ID 和删除引用细节按需展开。角色/变量创建后回到原场景，场景创建后进入新场景。场景默认沿用当前章节；仅移动所属章节也可提交，无须改名。删除包含场景的章节会阻断并说明原因。

背景等演出插入改用原生弹窗，资源显示名称、动作和缓动使用可理解的文案。选择项显示“选项 1/2”和“接下来进入”；名称唯一时隐藏目标/变量技术 ID，重名时仍保留必要区分。浅色主题下深色舞台选项文字的对比度已修正。

新增参数草稿保护：选择、跳转、变量等字段修改后，添加内容、切换场景、运行与结构操作先被阻断，可应用或放弃。数值、文字变量的默认赋值和条件按类型生成，避免把 `true` 写入数值变量。

### 真实任务中发现并处理的问题

- **实际产品阻塞**：结构页新增场景后，旧编辑器快照的场景数量不匹配，返回创作被旧原型检查阻断；场景改名也可能被旧来源覆盖。现在从已完成保存的结构页显式返回时使用当前工程内容，并保留同工程身份校验、本地修订号及正常重开/恢复合同；新内容标记为待保存。普通打开工程不启用这项显式衔接。
- **实际保存边界**：结构保存已写入工作区而后续回调失败时，重试使用已提交的版本号；重复保存与保存期间的结构操作被阻断。
- **验证脚本修正**：第一次访问的 5173 端口属于其他项目，改用本项目独立端口 5190；增加目标页面标题检查。后续修正了资源类型选择的歧义、立即刷新时未等待保存完成、目录媒体实际位于 `media/` 的错误假设。正常保存重开最终通过，未将保存尚未完成时的强制刷新算作正常重开失败。
