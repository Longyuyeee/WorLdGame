## 用户指出的画幅偏离与成品参考

第一轮实现虽然通过功能检查，仍沿用旧手机满高舞台和放大角色的策略。用户审阅横竖屏截图后明确指出显示比例不像正常成品游戏。复核实际 CSS：世界层有 `inset: -4%` 放大，竖屏以视口高度减去 26%/36% 决定画面、角色宽度扩大到 52%。它把作者的横向构图变成竖向裁切；脸部可见不代表原构图保持。这个方向偏离了同一工程跨屏幕呈现的目标，不能因路线能完成或按钮不重叠而验收。

对照了《ATRI -My Dear Moments-》的[官方 Android 商店实际游戏截图](https://play.google.com/store/apps/details?id=jp.co.imel.atri_gp)，并核对[官方 Steam 产品页](https://store.steampowered.com/app/1230140/ATRI_My_Dear_Moments/)。已目视的手机端游戏截图为约 16:9 的横向画幅，正文位于下部。此次只参考画幅、构图及文字区关系，没有安装/游玩其客户端、复制素材或将其许可视为本工程许可。该参考不证明所有 Gal 都必须 16:9，也不证明我们的浏览器游戏已达到其成品品质。

纠正后的规则：

- **演出画幅服从工程设计宽高。** 当前作品为 16:9；横屏按可用高度/宽度等比完整容纳，多余区域留黑，不拉伸世界层、不因手机变换作者 x/y/scale。移除旧 world overscan 和竖屏角色放大，角色基础宽度回到画面宽度的 30%。背景在手机布局 contain，保持原图。
- **横屏仍是游戏画面。** 文字在画面下部，字体和项目缩放相乘，常规框约四行预算；长段可以滚动/点按读下一屏，底部操作和继续提示与正文分开。不是缩小所有文字以塞进整段。
- **竖屏是备用阅读布局，不是竖向重构演出。** 上方仍呈现等比的 16:9 场景与角色，正文独立在下方；提示横屏更适合看演出，不强制方向锁定。没有将“读得完”包装为与横屏同样的演出体验。
- **宿主栏和安全区在布局预算内。** 单文件版本栏、目录离线栏展开/收起的真实高度继续计入 offset；正文不与菜单/存档相交。

最终几何检查：320×844 中画面为 **320×180**；390×844 中为 **390×219.375**；844×390（单文件顶部版本栏 24px）中为 **650.65625×365.984375**。三者 width/height 均为 1.7777777778，画面在舞台内，角色宽度/画面宽度保持 0.3。手机两条完整路线的每段继续检查画幅和操作区，而非只检查首段。截图已经目视复查；viewport resize 是浏览器尺寸变化，不是物理手机旋转传感器验收。

保留 `before-proportion-phone-*` 和 `before-proportion-browser-checks.json` 作为纠偏前证据；该 JSON 的功能 passed 不作最终视觉通过。当前截图为 `phone-320-reading.png`、`phone-390-reading.png`、`phone-*-landscape.png` 和 `http-expanded-toolbar.png`。竞品截图仅在临时浏览器中查看，不进入仓库/正式作品。

## 已完成的相连用户流程

1. 手机常驻历史、播放/快进设置及快速存读档改为单一阅读菜单，平时只留下菜单、存档入口及启用 Auto 时的停止入口；桌面控制仍保留。不是生成第二套状态或复制存档实现。菜单首焦点、Tab 范围、Escape/返回后的焦点和键盘控件操作受保护；gamepad cancel 可返回，菜单内不推进底层剧情。
2. 打开菜单暂停 Auto、停止 Skip，关闭后从当前段落继续。等待型视频/动效在菜单、历史或存档等覆盖层期间完成时延后确认；宿主暂停也不消耗该确认。延后信息绑定 Runtime state/Host snapshot hash，加载或回退后不能错完成另一项演出。媒体自身并非整个菜单期间强制静音/暂停，承诺是剧情推进冻结。
3. 长正文先读完本段：拖动不翻句，未读下方时点文字只前进约 80% 一屏；到底后再次点击才进入下一句。段落身份变化才归零滚动，开关菜单不把当前滚动重置。监听正文、字体/布局和视口尺寸变化，不依赖鼠标脚本直接写 scrollTop 来证明触控可用。
4. Auto 未读完下方时进入 `waiting-reading`，读到底才进入原时钟和语音结束等待；菜单/后台/选择/边界的旧停止规则保持。增加标准/从容/快速/原速四种独立阅读节奏，单位分别为 180/240/90/宿主 policy ms；不改 Skip 倍数或冻结的默认 policy v1.2.0。普通导出默认标准；明确自定义宿主 policy 默认原速，可由用户选择改变。
5. 阅读偏好只在本浏览器按 projectId 存储，不进入剧情、Canonical、Runtime hash 或存档；存储拒绝/无效值回退仍可读。系统减动效时即刻完成 reveal 状态，不再出现“文字已可见，但还得再点一次才算显示完”的隐藏等待。
6. 生产 Editor 正常 UI 导入 #308 工程，配置 1.4.0，导出源 ZIP、单文件 HTML 和完整目录；保持所有原正文、稳定 ID、71 步演出和 22 项素材，不把压力段落写进正式故事。

涉及 `PlayerShell.tsx`、`player-shell.css` 及小型 reading policy/surface helper。仍使用正式 PlayerCore、Runtime/Host、Scheduler 与存档路径；没有新解释器、裁剪历史或改写存档格式。
