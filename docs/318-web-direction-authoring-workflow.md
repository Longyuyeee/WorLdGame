# Web 演出素材与角色操作 · 2026-10-14

接续 `bc4e65bd`（#317）。本批沿“写场景 → 选素材 → 编排演出 → 保存重开 → 导出试玩”推进；当前《雨停之前》仍为 `evidence/web-save-backup` 的 1.5.4，没有重新发行作品版本。

## 已完成的实际操作

- 写作、演出工作区提供背景、角色、声音、镜头、对白框五个彩色快捷入口，显示实际插入位置；保留原语句工具与插入之前选项。
- 新增演出直接浏览兼容素材缩略图。已有演出换素材使用独立弹窗，支持名称/标签/标识搜索、12 项分页、当前选择标记、键盘退出和返回焦点；选择只更新参数草稿。
- 声音选中后原生控件试听，不自动播放。新增 BGM/环境声默认循环，配音/音效默认单次，仍可手动更改。关闭或换素材释放试听和图片对象 URL；图片预览也核对实际大小及摘要。
- 新角色默认使用整个工程中未占用的位置标识，保留其他角色。替换立绘、移动、退场可以按当前立绘名称选择对象；多位在场时新增移动/退场必须明确选对象。
- 对象列表复用舞台投影，根据本场景前序演出推导；高级位置标识仍支持跨场景继承的角色。**此列表不是完整分支执行结果**，需要完整试玩确认继承和路线。已有脚本标识保持原样。
- 演出动作与转场使用中文名称；角色精细坐标/缩放/锚点、过渡资源收起。无效高级参数仍在主表单提示。未应用保护、放弃、事务拒绝保留草稿、撤销/重做继续使用现有脚本事务。
- 没有素材时仍能创建清除背景、退场、停止音频等无需素材的演出。素材弹窗内 Enter 搜索不会隐式提交；Ctrl+Enter、Alt+数字不触发背景工作区插入。

五组实际流程：

1. 背景搜索/选择/放弃、弹窗键盘隔离/退出、手机布局；独立角色位置插入、撤销/重做。
2. 多角色选择移动及退场目标，精细参数收纳，浅/深主题和手机 Inspector；预览图片不超出容器。
3. 真音频文件实际播放试听、不同音轨循环默认值与插入。
4. 导出真实源 ZIP，核对角色目标/移动参数，逐项比较全部原素材 Blob 字节；保存、主页、刷新、重开。
5. 正式生成 HTML，以 `.html` 本地文件在 390 px Chromium 启动；两层 Canvas 立绘实际就绪，新增对象移动到 70%，指定原对象退场后新增对象保留，短篇走到“演出完成”。

浏览器工具即时组合 #317 的 4 场景测试骨架和 1.5.4 的 22 个原素材 Blob，只有入口场景的短篇用于上述流程；其余场景不代表路线覆盖。两个立绘层使用小夏的不同图作为测试对象。真实 ZIP/HTML 大小与 SHA256 保存在报告，下载文件在临时目录核验后释放，避免重复提交约 57 MB 的素材产物；可从工具及已有源包重建。

## 初始失败与调整记录

- `regression-initial.log` 的两项断言错误假设角色列表按插入顺序排列。列表实际使用舞台层级/槽位顺序；修改为核对对象集合，多对象默认不自动选目标。
- 测试组合工程最初重复使用其他场景的 `line_a` 标识，之后素材 bundle 的 projectId 未跟随测试工程更新，导入正确拒绝；分别修正测试数据，见两个 fixture failure 报告。
- 测试工具错误假设重做会自动选中新增步骤；改为重做后明确选择该步骤，再进行移动。产品没有更改撤销的选中语义。
- Playwright 下载临时路径没有扩展名，Chromium 按文本打开；改成带 `.html` 后缀的临时副本。之后脚本仅查 `img`，遗漏实际 Canvas；改为核对舞台层、Canvas 就绪和真实位置。对应 failure 报告保留。
- 首次素材库内嵌在 Inspector 时受舞台区域挤压，改成换素材弹窗。成功后最后截图仍发现网格的百分比图片高度撑开内容及搜索框继承纵向布局，修正 CSS 并复跑同五组流程；`browser-before-preview-fit.json` 是这次调整前的成功记录，不另计完成量。
