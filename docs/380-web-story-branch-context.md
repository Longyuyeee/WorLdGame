- [实际浏览器记录](../evidence/web-story-branch-context/browser-checks.json)：Chromium 九组检查。编辑器从入口到达两结局；独立 HTML file 桌面留下路线、网站 HTTP 手机尺寸远行路线各完整 66 段正文／6 句语音自然结束，合计两结局。两种格式的脚本与源工程一致，26 份媒体与源摘要一致，网站 37 文件逐份校验；内部来源台账、校订和兼容回执不进入玩家项目。

- 两个分支的新内容位置实际快速保存、后退已读句、刷新再读，恢复原 hash、正文、历史游标和长度、人物／背景／雨声；补测手机留下路线也通过。通关后读回通关前槽位，新的独立收藏仍保留，hash 因收藏合并变化属既有规则；回想退出恢复父剧情。

静音原生音频的播放时钟与 ended 检查不是人耳听感；桌面 Chromium 触屏尺寸不是实际手机或 Safari。#378／#379 的其他引擎、离线更新和阅读定位历史结果保留，本批未重新验证全套离线升级或三引擎完整路线。

只读重验候选可运行 `node tools/audit-rain-story-branch-context.mjs`，守卫测试为 `node --test tools/audit-rain-story-branch-context.test.mjs`。实际制作脚本 `node tools/run-web-story-branch-context.mjs` 需要当前 Editor 生产预览（默认 5195，可用 STUDIO_UI_URL 指定），会从原工程重新制作并覆盖本批输出；`--play-only` 只重新游玩现有输出，`--phone-left-only` 只补手机尺寸留下路线。重新制作前先保留当前交付，不将预期差异函数当生产源写入器。
