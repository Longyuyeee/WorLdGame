# Web 场景回想入口与重开流程 · 2026-10-15

接续 `48e6481`（#323）。先解决真实作品场景回想入口缺失，再完成结局回想、退出、标题重开与旧记录恢复。

## 已完成

- 根因：一次 Runtime 执行会在跳转/选择后继续执行新场景内容，History 的可观察边界错过 `instructionIndex = 0`；历史压缩又可能移除旧入口。
- 增加 Runtime 入口追踪，复用同一个解释器。Core 从新提交的正式 History 步骤中提取实际进入场景时的变量、调用栈、随机状态和继承演出；核对执行结果与已提交状态摘要一致后收录。普通执行结果和 Runtime/存档格式保持。
- 每个回想场景保留最近一次实际走过的入口，独立于普通回滚历史。手动阅读与正式自动/快进批次均收录；达成对应结局之后才开放回想。新路线和返回标题保留两条路线各自的入口。
- 入口在当前浏览器按工程/精确 build ID 独立保存。刷新后标题可直接回想，退出回到标题；从游玩中进入则返回原 Runtime、Host、历史位置。回想不覆盖正式存档、恢复点、收藏或入口记录。
- 加载已有正式存档时，利用其仍保留的活动 History 重建入口；没有足够记录的旧档继续明确提示读取其他存档或重走路线。没有用初始变量补造路线。
- 入口读取检查 Runtime Save、工程/构建、场景、入口边界、继承 Effect 和内容摘要。坏记录保留，附加内容提供失败提示与重试。摘要用于检查损坏，不是作者认证；同步仍不提供跨窗口原子写入。
- 回想结尾显示“回想结束”；按钮、空格/Enter 和 Escape 可返回原进度。修复焦点落在按钮时 Escape 被交互元素过滤器拦截，并清除进入回想前的旧存档成功提示。

## 必要验证

- 10 文件、197 个不同相关测试通过；Escape 修正后重跑相关 Shell 两文件 8 项，属于已有测试，不累计。覆盖 Runtime 原合同、入口追踪、选择变量、调用栈、正式播放批次、历史压缩、旧档重建、标题恢复、锁定内容、损坏/配额拒绝和原回想隔离。
- 根类型与 Player/Editor 生产构建通过；原 500 kB chunk 提示仍在。
- Chromium 155.0.8059.41 的 4 组生产浏览器流程通过，page errors 为空。最终布局修改后另跑 1 组定向检查，不重复计入完整路线。

实际流程：

1. 从实际编辑器导出 HTML 和目录。HTML 走完留下路线，保存真实结局槽位，进入“雨后的天明”并播放至回想结尾；空格返回后 Runtime、Host 摘要、History 位置和原结局全部一致，回想中的存读档入口隐藏。
2. 返回标题并刷新，无需读档即可回想，再回标题。只删除隔离测试资料中的新增回想档案，模拟已有收藏和旧槽位、尚无新档案的环境；通过真实槽位读取重建入口，再进入回想并以 Escape 精确恢复原结局。没有植入解锁或修改剧情变量。
3. 同一游戏再走远行路线，返回标题刷新，两段回想都可用；完成另一条路线后仍可重温先前路线并返回标题。
4. 独立浏览器的 390 px HTTP 目录走完远行路线，进入“再一次见面”、退出并恢复原结局；刷新标题后直接进入和退出回想。

实图发现竖屏场景名被长按钮挤短、横屏提示条遮正文，缩短可见退出文案、保留完整可访问名称，并调整定位。最终重新导出，用实际“快进全部”走完远行路线后只检查布局：390 px 场景名完整，844×390 提示条在正文上方，退出仍保留原状态。完整手动流程结果为 `browser-checks.json` / `browser-final.log`，最终布局/生成摘要为 `browser-layout-final.json` / `browser-layout-final.log`；截图含 `desktop-both-replays.png`、`desktop-replay-ended.png`、`mobile-replay-final.png`、`mobile-landscape-replay-final.png`。双导出仅用于临时验证并已清理，没有重复提交大包。

初始浏览器检查已实际播放《雨停之前》的回想到结尾、验证空格返回和刷新标题直达；继续检查旧档重建时暴露聚焦按钮上的 Escape 失效，已修正并保留初始失败截图/报告。本批不通过改写解锁或变量模拟回想。旧 #323 脚本随入口可用性更新，新 #324 脚本覆盖相关流程，不另重跑其完整脚本。

## 边界与后续

《雨停之前》源工程和原候选仍是 `evidence/web-save-backup` 的 1.5.4；本批只临时导出验证，没有重发候选。旧档被压缩掉且本机未另存的入口和演出记录无法凭空恢复，需要更早的完整存档或重新走过路线。独立回想档案目前不自动跨版本/来源/设备迁移，也不随单个存档备份携带；导入的会话可从仍保留的 History 重建。
