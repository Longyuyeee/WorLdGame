# Web 阅读操作收纳与演出欣赏 · 2026-10-15

接续 `99ff9bd`（#320）。实际玩家画面把历史、播放参数和存档工具长期叠在舞台上，本批完成阅读操作收纳，并用正式作品验证导出后的游玩流程。

## 已完成

- 桌面底部集中后退/前进、历史、自动、已读快进和存档；舞台上方保留菜单与画面欣赏入口。
- 桌面与手机使用同一阅读菜单，按“回看与内容 / 自动阅读与快进 / 进度与备份”分组；详细速度、激活方式、语言和快速存取在菜单中展开。关闭时这些控件同时退出浏览器可访问/键盘顺序。
- 菜单打开后剧情暂停推进、Tab 保持在菜单内、Escape 返回可见入口；调整窗口不会关闭菜单。进入设置或附加内容后，返回焦点落在可见菜单按钮。
- 从菜单启动快进时先返回故事，修复快进因菜单仍打开而立即停止的问题；自动阅读仍在菜单关闭后继续。
- “欣赏画面”保留作者画幅、隐藏对白和工具、停止自动与快进。点击、H、Escape、Enter、空格或手柄确认/取消恢复阅读；恢复本身不推进一句。原文、阅读滚动和 Runtime/History 保留，按住 H 不反复切换，表单与弹层输入不触发快捷键。
- 等待视频可欣赏画面。结束事件在隐藏期间暂存，返回后沿既有 Runtime/Host 同状态与前台活动门禁完成；不把旧结束事件交给另一个读档位置。背景音乐和媒体时钟不因画面欣赏而复原。
- 修正菜单外按钮遮挡、手机弹层顶部空位、高对比说明文字和竖屏欣赏画面的居中；历史/附加内容改为按视口定位，避免新的桌面操作栏将弹层挤到画面外。
