## 玩家问题与处理

原网站版的“离线与安装”和版本行默认占用 68px，即 844×390 横屏高度的约 17.4%；状态文字变长时还会继续挤压舞台。原单文件 HTML 另有 24px 常驻版本行。对照 [修改前横屏](../evidence/web-publication-reading/before-844x390.png)和[本批横屏](../evidence/web-publication-reading/updated-844x390.png)，网站版阅读顶部占用由 68px 降至 **0**。这不是将游戏拉伸填满屏幕：演出仍保持作者 16:9 构图，竖屏继续上图下文。

版本在标题页和阅读菜单中查看；网站／目录版同处提供“离线与安装”，单文件 HTML 只显示游戏信息，不提供其不支持的网站离线按钮。简短状态显示在折叠标题，完整下载、失败、缓存条件及更新警告在展开内容中。长说明只增加菜单自身的滚动内容，不再改变正文视口。控件沿用作品颜色和高对比设置，触控目标至少 44px。

游戏信息直接进入现有标题操作区／菜单内容区，不另建浮动按钮或弹窗。打开阅读菜单继续沿用原有暂停推进规则，返回和 Esc 恢复原段落及焦点。Tab 包含折叠标题，排除隐藏、禁用和已折叠内容中的按钮；标题页聚焦折叠项时 Enter／空格不触发开始故事。

## 下载与更新生命周期

导出页保留一个隐藏的原始容器，标题页或阅读菜单仅临时承接同一份游戏信息 DOM。React 只管理空槽位，不重建离线按钮、事件监听或下载请求；离开页面区域时折叠并还回原容器。下载可在标题页开始，继续阅读，再打开菜单核对状态。加载、取消和资源错误时原容器可见，仍可查看版本和离线说明；成功挂载后由标题／菜单承接。

未改变 Service Worker 的文件摘要核对、缓存范围、Range 响应、旧缓存保留或等待激活规则，没有自动刷新、skipWaiting 或强制安装。新旧外壳虽然都标记 1.8.0，实际文件摘要变化仍生成新缓存身份；只有所有原游戏窗口关闭后才使用新外壳。当前故事内容和原同版进度保持。

[实际浏览器检查](../evidence/web-publication-reading/browser-checks.json)共 **10 组任务**，范围为：
