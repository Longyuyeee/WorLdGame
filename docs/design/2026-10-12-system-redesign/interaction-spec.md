# 全界面与交互规格

状态：第一轮可评审方案。示例作品为《雨后的约定》。26 个页面在原型中可到达；各页面的详细业务状态由本文定义，原型实现高频动作、层级、返回和代表性异常。设计不等于所有业务能力已经实现。

## 1. 对现有界面的具体诊断

根据 `App.tsx`、`WorkspaceHeader`、`ProductionWorkspace`、`SettingsWorkspace`、`DebugQaWorkspace` 与现有 evidence 截图：

| 当前表现 | 使用中的问题 | 新设计落点 |
|---|---|---|
| 顶部 7 种岗位模式、3 种内容视图、Beginner/Pro、动效等级并列 | 不知道应该先选模式还是视图，选择之间存在重叠 | 任务主导航 + 场景内三视图；密度和动效移到编辑器偏好 |
| PreviewPanel 同时承担预览、运行、参数、导出与优化报告 | 写作时需要辨认与当前任务无关的信息，预览空间被挤占 | 预览按需；发布独立页面；报告在发布结果下钻 |
| 选中语句后，完整编辑表单接着列表往下铺 | 需要滚动离开正文，当前对象与表单关联不直观 | 正文直接编辑；低频属性在明确标题的抽屉 |
| 项目树附带 Source of Truth、资源保管库和协议状态 | 技术说明占用导航空间，普通作者难以理解 | 项目树只承载章节/场景；诊断信息进入高级设置 |
| Production 在同一处承载素材、本地化、配音及批量状态 | 一个岗位标签下混入多个长任务 | 素材库、本地化、内容收录分别有地址与返回路径 |
| Settings 默认 all 且混合基本/专家、作用层、平台、事务 | 填配置前要先理解实现结构 | 分类页面 + 少量常用字段 + 按需平台覆盖 |
| 调试器同时展示断点、Watch、变量、调用栈、可见对象与 QA 指标 | 普通检查和运行调试混在一起 | “问题”与“调试”分开；日志/调用栈折叠到调试详情 |

## 2. 固定的信息架构

```text
项目首页
├─ 新建 / 导入工程
└─ 项目工作区（打开时回到上次编辑场景）
   ├─ 故事
   │  ├─ 章节与场景 → 场景 → 写作 / 演出 / 脚本
   │  ├─ 路线 → 场景详情 → 同一场景编辑
   │  ├─ 角色 → 角色详情 → 表情与立绘
   │  └─ 变量 → 变量详情 → 引用位置
   ├─ 素材
   │  ├─ 素材库 → 素材详情 / 导入 / 替换与引用
   │  ├─ 本地化与配音 → 文本逐条编辑 / 翻译交换
   │  └─ 内容收录 → 画廊 / 音乐室 / 结局 / 场景回想
   ├─ 游戏外观
   │  ├─ 游戏界面 → 标题 / 对话框 / 选择 / 菜单
   │  └─ 玩家默认设置 → 文本 / 声音 / 输入 / 无障碍
   ├─ 检查
   │  ├─ 问题 → 定位 / 修复 / 有理由地忽略
   │  └─ 调试 → 运行 / 变量 / 断点 / 日志
   ├─ 发布 → 平台与形式 → 检查 → 导出 → 交付结果
   └─ 设置（固定次要入口）
      ├─ 项目信息 / 编辑器外观 / 保存 / 平台 / 高级
      └─ 备份与恢复 → 差异预览 → 确认恢复

试玩（独立全屏上下文，返回编辑器恢复原位置）
├─ 标题 → 开始 / 继续 / 读取 / 回忆 / 设置
├─ 阅读 → 选择 → 结局
├─ 存档 → 手动 / 自动 / 快速 → 读取 / 覆盖 / 删除
├─ 历史 → 当前路线 / 旧分支 → 可用回退位置
├─ 游戏设置 → 阅读 / 声音 / 语言 / 无障碍
└─ 回忆 → 画廊 / 音乐室 / 结局 / 场景回想
```

章节和场景使用真实名称。工作模式的英文名不再成为导航。角色、变量或素材在不同页面打开时始终引用同一业务对象。

## 4. 页面、抽屉、对话框的使用规则

- **独立页面**：需要搜索、连续编辑、反复返回或结果历史的任务。例如素材、本地化、检查、发布、备份。
- **抽屉**：需要保持背景内容可见的单对象详情。例如素材引用、角色、当前语句属性、节点简介、舞台动作。桌面从右侧出现；手机替换为全屏二级页。
- **对话框**：可在几十秒内完成的一件事。例如新建、命名、短确认、增加内容类型。宽度 480–640 px；键盘焦点保持在内部。
- **复杂局部编辑**：选项、条件、导入差异、关键帧使用大二级编辑面。进入目标或素材选择时保存局部草稿，顶栏“返回”回到父步骤。
- **Toast**：只用于明确成功且无需决定的反馈。保存失败、阻断错误、进度是否安全必须保持可见。
- 不能弹窗中再叠弹窗。最大同时存在一个拥有焦点的覆盖层。内部下钻用返回栈，显示当前任务标题，恢复父任务草稿。
- 点关闭、Escape 或返回恢复发起控件的焦点。涉及未完成输入时先选择“保留草稿 / 继续编辑 / 放弃”，不静默丢内容。
- 真正删除、覆盖、恢复都显示具体对象和影响。可撤销内容提供撤销；永久删除或版本恢复采用明确确认。

## 6. 五条必须顺畅的作者任务

### 从零写出可以试玩的故事

首页“新建工程” → 命名与起步模板 → 第一场景写作 → 点正文输入 → 添加内容 / 背景 → 类型过滤后的素材选择 → 回到原句 → 试玩。预览从当前句和“从头试玩”清晰区分。新工程不要求先填写角色资料、变量、发行选项或调试设置。旁白和匿名主角允许起步；真正需要的引用在使用时补齐。

### 编辑一条选项并检查走向

写作中的选择摘要 → 编辑选项 → 文本与目标 → 需要时展开条件和赋值 → 选择目标子页 → 返回时保留已输入文本 → 完成 → 原位置更新摘要 → 路线页面看到走向 → 打开目标场景。全局路线不展开每句对白。无效或缺失目标在选项旁显示，并给出选择场景入口。

### 素材缺失时修复工程

持续横幅或问题检查 → 缺失素材详情 → 原名称、引用位置与故障原因 → 从库中关联或重新选文件 → 预览影响 → 确认 → 回到发起位置。素材替换沿用稳定 ID；需要换身份时显示引用迁移，不要求作者手工理解内部哈希或清空数据。

### 翻译和配音

素材 / 本地化 → 选目标语言 → 按状态筛选 → 当前文本编辑面 → 译文、排版预览与配音 → 保存并下一条。导入 CSV/XLSX 先展示差异；未知键、格式错误、同一键重复、缺资源在提交前可修复。工程源语言变更导致译文过期时保留旧文并显式标记，不静默使用失效译文。

### 导出给其他人玩

发布 → 选当前真正支持的平台 → 选交付形式 → 检查 → 阻断问题可回源修复 → 返回原步骤再检查 → 生成 → 明确产物名、保存位置、试玩与启动说明。优化默认安全方案；只有需要时进入高级项。Android 尚未交付时标明状态且不可点；Windows 需真实宿主时说明该设备能否构建。结果和性能报告不占创作工作区。

## 7. 玩家完整使用流程

- 冷启动扫描恢复点期间保持标题布局与按钮位置。扫描完成后显示“继续 · 场景 / 时间”；无恢复点时不出现无效“继续”。超时可重查，失败不假装是新游戏。
- 阅读页优先画面与对白，常用操作通过少量工具条或菜单到达。展开历史、存档、菜单即暂停自动推进；返回后重新等待；快进停止，不自动重开。
- 保存与读取分别强调动作。空槽只提供保存；有档槽的“读取”和“覆盖”分开。自动/快速档展示来源，不要求玩家理解 Runtime 版本。
- 读取失败仍保留当前句，说明损坏 / 不兼容 / 加载能力不足，并提供重试、选其他档和可展开详情。展示元数据成功不能误称正文可以读。
- 历史可回退行显示“回到这里”；仅能阅读的归档明确说明不可回退。选择、屏障或旧分支不隐去原因。回退前说明将切换当前阅读位置。
- 缺少图片、权限阻止音视频、网络或解码超时都有“重试画面 / 恢复声音 / 恢复视频”入口。错误保持当前位置，不用工程术语代替玩家行动。
- 回忆页四种内容同级切换。锁定项不剧透名称与缩略图；不成功播放的音乐不计已播放。场景回想明确独立于主进度，退出回忆返回原列表。
- 结局页显示结果和解锁提示，能保存、看回忆、回标题或重新开始。所有退出动作先确保最近进度是否安全。

## 8. 统一状态合同

| 状态 | 界面表现 | 用户可执行 | 数据要求 |
|---|---|---|---|
| 空工程 / 空列表 | 有明确第一步的空态 | 创建、导入、取消筛选 | 不制造演示项目冒充数据 |
| 等待 | 动作区域给真实阶段与取消边界 | 取消或稍后返回 | 不能把未知进度包装成百分比 |
| 正在保存 | 顶栏小状态，写作不中断 | 继续编辑 | 快照与写入顺序沿用现有持久化 |
| 保存失败 | 持续横幅，明确未安全保存 | 重试、导出副本 | 旧安全版本保留；不显示已保存 |
| 只读 / 另窗占用 | 状态条与编辑禁用 | 查看、退出另窗、导出副本 | 不夺取写入权或清掉锁 |
| 更高格式 / 迁移中 | 独立状态面 | 只读/升级后打开/导出可得副本 | 失败不改原数据 |
| 草稿不合法 | 源位置与原因，草稿仍可保存 | 修复、继续其他场景、明确放弃 | 阻止正式编译、试玩、发布 |
| 素材缺失 | 对象和引用可见 | 重关联、替换、重试 | 保留稳定身份及原引用 |
| 导入冲突 | 差异预览 | 选择替换、保留、排除、取消 | 通过确认前不部分写入 |
| 未支持的平台 | 状态说明与禁用动作 | 选择可用平台 | 不模拟真实导出 |
| 玩家坏档 | 原位置保持与持续错误 | 换档、重试、展开详情 | 正文校验失败不应用部分状态 |
| 玩家进度保护失败 | 明确尚未安全保存 | 等待/重试，不引导直接关游戏 | 失败前不裁剪历史 |

原型顶端状态选择器是设计评审控件，不是正式产品功能。当前代表性状态可以现场切换；最终实施需要上述全部状态接入真实业务。

## 9. 桌面、平板、手机

- 桌面 ≥1200：118–160 px 主导航，168–220 px 场景导航，正文居中。写作默认不常驻属性和大预览；演出可以有 240–300 px 属性栏。
- 平板 768–1199：缩窄任务导航，隐藏低频属性；场景列表可抽屉打开。演出采用画面 + 单个辅助区，不能三个窄表单挤在一起。
- 手机 320–767：单列主内容；四个常用导航“故事 / 素材 / 检查 / 更多”，游戏外观、发布、设置在更多中。场景切换进入章节列表；写作、演出、脚本是当前场景的子视图。原型的设备选择为“手机”时使用四入口底栏，自动窄屏布局也使用这套结构。
- 手机属性、选项、翻译和素材选择是全屏二级页，返回目标明确；编辑时留出键盘与安全区。文本输入字号 ≥16 px，触摸目标 ≥44 px。
- 移动路线默认清单，局部分支进入图视图。操作菜单可替代拖线、拖拽和精确拖动。
- 不把模拟手机尺寸视为实体设备验收。实施时用真实触控、IME、键盘、Android/WebView、系统后台与长时运行验证。

## 10. 设计可用性的验收任务

1. 不看教程找到当前场景，改一句话，试玩，再回到原句。
2. 新建场景，插入背景与音乐，修改后保存，关闭重开。
3. 加选项、指定目标、加条件，再从路线进入目标场景修改。
4. 从缺失素材通知修复引用，回来后光标和滚动仍在。
5. 翻译一条并绑定配音，连续处理下一条；错误导入不部分提交。
6. 导出一个 Web 游戏；找到产物和启动方式；失败能回源修复并返回原步骤。
7. 手机连续写五条对白；在键盘开启时选场景、改选项、关闭属性，不能丢草稿或误触背后页面。
8. 玩家冷启动继续，阅读到选择，保存，读档，回退，回标题再继续；错误媒体可恢复且不跳句。

记录用户是否找到入口、实际点错、迷惑语言、被阻断原因与恢复结果。系统真实可用后再评审满意度；通过截图或点击原型不记作真实任务全部通过。
