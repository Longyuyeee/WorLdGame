# 质量与发布体系

## 1. 质量目标

视觉小说编辑器最严重的问题不是单次崩溃，而是：

- 工程损坏；
- 分支静默丢失；
- 可视化和脚本语义漂移；
- 发布平台行为不一致；
- 更新后旧存档失效；
- 本地化或配音错位；
- 构建证书泄露。

质量体系优先保护创作者资产和已发行作品。

## 2. 测试分层

### 2.1 单元测试

- Parser/Formatter Round-trip；
- 表达式与类型系统；
- AST 语义命令及逆操作；
- 引用、重命名和删除；
- 资源清单与哈希；
- Runtime 每条 Opcode；
- 保存、加载和回滚；
- 迁移函数；
- 诊断规则；
- 插件权限判断。

### 2.2 属性与模糊测试

- 随机有效脚本：parse → format → parse 语义不变；
- 随机 AST：可视化修改 → 序列化 → 解析语义不变；
- 压缩包、图片、字体、媒体导入器；
- 旧版本工程迁移；
- 随机命令序列的撤销全部恢复初始状态；
- 保存/加载后 VM 状态等价。

### 2.3 集成测试

- Script、Sequence、Route、Stage 同步；
- 外部文件变化与三方合并；
- 资源重命名与跨场景引用；
- 插件安装/缺失/升级；
- 本地化导出导入；
- 预览热更新；
- 构建输入和 Runtime IR；
- 云同步中断与恢复。

### 2.4 端到端测试

同一模板项目在 Windows、Web、Android、iOS 上执行固定路线，比较：

- 当前语句 ID；
- 变量；
- 调用栈；
- 可见角色与背景；
- 音频状态；
- 存档加载结果；
- 回滚结果；
- 截图差异。

### 2.5 真实设备

最低矩阵：

- Windows 10/11，x64；
- Android 低/中/高内存机，至少两个系统主版本；
- iPhone 小屏与常规屏、iPad；
- Chrome/Edge/Firefox/Safari 最新稳定与前一主版本；
- 横屏、竖屏、刘海/挖孔和不同 DPI；
- 触摸、鼠标、键盘和输入法。

## 3. Golden Projects

维护不可随意修改的样板工程：

1. **Tiny**：五分钟、两分支；
2. **CJK**：中日混排、Ruby、禁则、字体回退；
3. **Media**：大图、长音频、视频和转场；
4. **State**：变量、调用、循环、随机、保存和回滚；
5. **Localization**：五语言、配音和本地化资源；
6. **Large**：10 万字、1 万场景索引压力；
7. **Plugin**：已安装、缺失和升级插件；
8. **Legacy**：每个已发布格式版本与代表性旧存档。

所有发布候选必须构建并运行 Golden Projects。

## 4. Story QA 规则

### Error

- 无入口或多个入口；
- 跳转/调用目标不存在；
- 选择项没有出口；
- 确定性无暂停死循环；
- 必需资源缺失；
- 表达式类型错误；
- 插件或 Opcode 不兼容；
- 发布目标必需签名无效。

### Warning

- 不可达场景/结局；
- 变量先读后写；
- 资源未使用或重复；
- 文本可能溢出；
- 没有 Alt 文本；
- 配音/翻译过期；
- Web 不支持的媒体格式；
- 旧存档可能无法定位。

### Suggestion

- 场景过长；
- 路线复杂度过高；
- 资源尺寸可优化；
- 重复演出可提取宏；
- 文本速度与语音时长差异明显。

## 5. 性能测试

每次发布记录：

- 启动时间；
- 峰值/稳定内存；
- 输入延迟；
- 增量编译时间；
- 搜索时间；
- Route Map FPS 与节点数量；
- 预览热更新时间；
- 玩家首屏下载；
- 构建时间和缓存命中率；
- 运行时帧时间和资源峰值。

性能退化超过预算 10% 必须说明或阻止发布。

## 6. 视觉回归

- 固定字体和渲染环境；
- 每个 UI 模板、多语言和设备比例截图；
- Stage 与最终玩家包截图比较；
- 转场使用关键帧/视频短片比较；
- 允许抗锯齿阈值，但文本布局变化单独检测；
- 本地化溢出截图作为 QA 产物。

## 7. 无障碍门禁

- 编辑器完整键盘路径；
- 屏幕阅读器基础任务；
- 200% 缩放；
- 高对比度；
- 减少动效；
- 手机触控目标；
- 运行时自述、Alt 文本、字幕、分通道音量；
- 不用颜色作为唯一状态。

P0 流程无法仅用键盘完成时，不允许发布桌面正式版。

## 8. 安全测试

- 路径穿越和 Zip Slip；
- 解压炸弹、超大图片和恶意字体；
- SVG/HTML/脚本同源隔离；
- 插件权限升级；
- 依赖供应链扫描和 SBOM；
- 构建日志密钥扫描；
- 多租户 Worker 隔离；
- 签名凭据访问审计；
- 账户、分享链接和删除流程；
- 本地工程默认不上传验证。

## 9. 发布渠道

### 编辑器

- Nightly：自动构建，不保证工程兼容；
- Preview：供早期试用，带迁移备份；
- Stable：通过全部 Golden Projects；
- LTS（团队版后）：长期格式和存档支持。

### 运行时

- Runtime 版本与编辑器版本分开；
- 已发布项目可锁定 Runtime；
- 安全补丁允许在兼容范围内升级；
- 大版本升级前提供兼容报告。

## 10. 版本规则

- 工程格式：独立 Schema 版本；
- Runtime IR：独立版本；
- Plugin API：独立版本；
- Editor：语义版本；
- Build Template：不可变版本号；
- Save Schema：独立版本。

不能用一个应用版本号代表所有兼容关系。

## 12. 故障与数据恢复

- 自动保存采用写前日志/操作日志；
- 原子替换源文件；
- 迁移前创建快照；
- 崩溃后先只读检查，再提供恢复；
- 保留最近多个本地恢复点；
- 云同步不覆盖唯一副本；
- 删除项目默认进入可恢复区；
- 明确展示“只在此设备”“已备份”“同步中”“存在冲突”。

## 13. 遥测与隐私

- 默认只收集崩溃和基础性能，允许完全关闭；
- 不上传剧情文本、资源名、项目路径和媒体；
- 诊断附件由用户预览后主动发送；
- 云构建资源保留期限透明；
- 用户可导出和删除账户数据；
- 团队管理员不能绕过创作者明确的数据范围。
