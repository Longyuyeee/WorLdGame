# Web 结局收尾与收藏保留 · 2026-10-15

接续 `ffa7cb1`（#322）。本批沿玩家“走到结局 → 查看收藏 → 重开或读另一条路线 → 下次继续查看”的流程推进。

## 已完成

- 结局卡片显示已达成数量，提供查看收藏与结局、读取存档探索其他路线、回到标题三个入口；沿作品主题，手机和短横屏可滚动。
- 修复回到标题、新故事初始化丢失已读和解锁记录的问题。新路线使用新的剧情执行与初始变量，保留原有已读、画廊、音乐和结局；读取旧路线存档同样合并现有收藏。
- 收藏独立保存在本机浏览器，按工程和精确 Compiler build ID 分开；相同版本刷新后，标题不必先读取剧情存档就能看到收藏。读取记录走 Runtime 的正式结构/工程/范围校验；未改变 Runtime 和存档格式。
- 普通阅读合并后延迟 400 ms 保存，结局/标题及时保存，并处理 pagehide 和同源 storage 通知。不可读的旧记录保留，写入失败时仍保留内存记录，附加内容和结局页提供提示及重试。
- 回想列表依据真实历史中的场景入口判断可用性。仅解锁、缺少可用入口时提前说明并禁用，提供读取路线存档入口；可用回想继续走原隔离与恢复流程，不将回想中的发现写入正式收藏。

- 根类型检查与 Player/Editor 生产构建通过；原 500 kB chunk 提示仍在。
- Chromium 155.0.8059.41 的 3 组生产浏览器任务通过，page errors 为空；从实际编辑器导出 HTML 与目录，没有修改测试中的游戏状态或植入解锁。

实际任务：

1. 桌面 HTML 走完留下路线，显示 1 / 2 结局，查看实际画廊图片、音乐和结局。回想缺少安全入口被禁用并说明，关闭后剧情摘要和历史位置保持；返回标题及刷新后收藏保留，不读取剧情存档。

## 边界和下一步

源工程及原候选仍是 `evidence/web-save-backup` 的《雨停之前》1.5.4。新游戏只临时导出验证，未重发候选。收藏存于当前浏览器和来源，清除站点数据会清除它；独立收藏不自动跨版本、来源或设备迁移，读取已核对的存档后可保留该会话携带的记录。storage 通知和写前合并不提供跨窗口同时写入的原子保证。

未新增人工正文/听感定稿、真机/其他引擎、许可/公网、旧档离线更新整链、全仓或长期运行验收；原长篇长帧继续开放；《雨停之前》当前回想入口缺失也继续开放，提供有入口的路线存档之前不能重播。Windows/Android 原生继续搁置。下一批继续处理创作者定稿过程中的实际操作与交付障碍。
