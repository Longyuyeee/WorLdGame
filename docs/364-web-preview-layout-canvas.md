## 作者操作

在“游戏外观 → 标题画面／阅读与选项”启用本页自由布局，点击右侧“编辑预览布局”。左侧参数、画布组件和桌面／手机设备选择相互同步；被隐藏或相互遮挡的组件也能从列表选择。可放大预览，在大舞台上编辑。

- 拖动编辑框移动，拖动所选框右下角调整尺寸。鼠标和触摸均走 Pointer Events。
- 框获得焦点后，方向键移动安全区尺寸的 1%，Shift 加快至 5%；Alt 加方向键调整宽高。
- 拖动期间只更新编辑框，松开才生成一次外观草稿修改；真实播放器随后使用草稿重载。一次“撤销外观调整”可还原整次拖动，重做可恢复。
- Esc、触摸取消、丢失指针捕获、窗口失焦、页面隐藏或编辑期间尺寸／源稿变化，会取消未提交的拖动。单击选中不产生修改。
- “结束布局编辑”后恢复实际游戏操作。编辑期间 iframe 不接收点击和键盘焦点，移动框不会开始故事、打开游戏菜单或推进正文。

坐标仍使用 #363 的整数百分比与九锚点契约，没有另存一套像素布局。拖动从实际边界位置起算，优先保留原锚点；原锚点无法在 ±50% 偏移内表达时，对应轴转为中央锚点。位置有百分比取整，最小可读／触摸尺寸及安全区继续优先。手机编辑首次产生独立配置，不改桌面位置。

## 冲突与手机显示

画布编辑框使用与正式 Player 相同的安全区和几何计算；冲突位置以虚线标出，真实游戏仍执行保护。下方列出具体组件、越界或遮挡原因，并提供定位。

主组件相互遮挡时，“恢复两组安全布局”明确同时恢复当前设备的两组主组件，不修改其他设备；整批可撤销。仅越界时可以采用当前安全位置。自定义按钮的“寻找可用位置”在当前舞台按有限网格查找，并重新经过正式几何计算验证，不接受取整后仍遮挡的位置。未找到时保留操作区回退，提示手动移动、缩小或隐藏，不宣称穷尽所有排布。

自定义文字、图片和按钮增加“组件显示设备”：两端显示、仅桌面、仅手机。手机类仍包括宽度不超过 800px 或高度不超过 480px 的视口，横屏手机不会自动显示桌面装饰。隐藏组件不进入正式 DOM、不参与操作遮挡计算，也不可通过 Tab 或点击触发；位置、素材和动作仍保留，便于切回另一设备。开始、正文与原有返回入口不能通过此开关隐藏。

图片在手机隐藏不等于删除或裁掉包内字节。其引用继续参与素材校验、导出、跨工程对应及缺图修复；旧组件未填写可见性时继续两端显示。

## 实现与审计修正

`PlayerLayoutCanvas` 只读取同源隔离预览中的实际舞台／安全区，编辑框位于编辑器侧；手势只提交 `WebPageLayout` 外观草稿，不写 Runtime、进度或正式存储。几何计算通过 `@world-studio/player-shell/layout` 复用，Compiler／Runtime／Player Core 未增加解释器。

`WebLayoutComponent.visibility` 是受限的可选字段，严格接受 `all`、`desktop`、`mobile`；未知字段、任意代码和跨页非法动作仍拒绝。旧配置可由当前版本读取，带新字段的配置不承诺旧应用可读。既有每页六组件、图片／字体／包大小限制保持。

真实操作发现并修复了“定位后残留焦点请求抢回选择，后续参数可能改错组件”的问题，补入回归。布局复选框也修正了被通用输入框样式放大的问题。冲突候选查找不会随每一个拖动像素重复执行；拖动未结束时不接受自动位置修正。早期失败截图与报告保留，最终通过不覆盖它们。
