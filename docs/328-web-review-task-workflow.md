## 已完成

- 从校订清单进入原文后，在故事页显示紧凑的“当前校订任务”：问题、类型、场景与状态持续可见，原记录内容收在详情里。可以直接标记已修改并复测、继续修改、确认已复核、处理下一条或返回清单；未应用的文字和脚本草稿会阻止离开。结束任务只收起当前任务，不删除记录。
- 局部复测实际调用正式 Core 从记录的步骤重新启动。任务条的确认按钮要求本次启动成功、到达原位置、运行和当前源稿一致、记录未变化；修改作品/记录、重启/退出试玩或刷新重开后，不能沿用旧复测确认。达到条件后仍由作者点击确认，不自动标记通过。
- 保留清单原有的人工状态操作；任务条的复测条件不是新增的全局发布门禁。局部启动使用默认变量，不代替从入口游玩的路线确认，也不会累计成完整结局完成。
- “下一条待跟进”直接打开下一条问题的原文，包含工程变化后需要重新复核的旧记录。原内容或记录删除后仍保留任务提示与返回清单的出口，不跳到错误内容。
- 清单增加折叠的搜索和问题类型筛选，搜索问题描述、记录时内容与新旧场景标题。待跟进/全部、搜索、类型和页码随本机工作位置保留；从编辑器返回时找到并突出原记录，已被筛掉时安全回到清单。
- 未完成任务刷新或主页重开后接续，首页提示“继续校订”。只记任务身份和阶段，不保存本次运行的确认依据，不自动启动试玩。桌面与 390 px 浅深主题已实看；手机任务条限制高度，复测成功后滚到实际预览；手机筛选为整行搜索、下一行类型和清除按钮。
- 从发布页的待校订提醒进入清单时保留“返回生成游戏”，完成后继续原导出格式和附带资料选择。实际生成的制作包包含明确确认后的记录，个人导航和任务位置不进入玩家游戏。
