## 内容变化与存档边界

1.8.0 修改了正文和演出，**不兼容 1.7.x 或更早剧情存档，不实现内容迁移**。实际上传原 1.7.14 工程做兼容核对，按预期显示内容变化；明确移除失效回执后生成，不把旧版核对列表复制进新版。原 1.7.14 工程、游戏、校订记录和之前兼容的 1.7.0–1.7.13 入口继续保留在 [web-reading-throughput](../evidence/web-reading-throughput)。旧玩家保留原版与备份继续游玩，新候选从头开始。

Chromium 在原 1.7.14 HTML 中实际创建一份进度备份，再用新网站游戏验证这份备份和原 1.7.13 备份均被拒绝；标题状态不变，不提供导入槽位按钮，不覆盖旧数据。不是仅篡改文件名或版本文本来测试。

同版读档区分两个契约：没有新增已读／收藏时，保存→回退→刷新→读取精确恢复正文、状态 hash、历史游标／长度、背景、人物和雨声音量；通关产生新已读／结局后，再读通关前槽位，应恢复原文与历史位置并保留新增收藏，合并后 hash 可以改变。初次工具错误地要求后一种情况 hash 也不变，失败保留在 [初次断言记录](../evidence/web-story-continuity/failure-2026-10-17T06-48-17-358Z.json)；对照原 Runtime 合并规则后分开验证，未削弱正式校验、删除收藏或修改 Runtime。

[创作／导出相关回归](../evidence/web-story-continuity/related-tests.json) **75 项、12 文件**，[保存与收藏](../evidence/web-story-continuity/save-collection-tests.json) **30 项、3 文件**，共 **105 项、15 文件通过，无失败或待测**。另有 7 项本批内容差异保护与 18 项原部署／构建／轮询工具测试通过，共 **25 项 Node 工具测试**；重复运行不累计。根类型、Editor／Player 双构建、118 便携／4 Node 适配文件架构审计、工具语法和差异检查通过。既有大 chunk 提示保留，没有跑全仓测试或重新测量长篇性能。

[Chromium 151 实际记录](../evidence/web-story-continuity/browser-checks.json)共 **9 组任务**。编辑器完整入口两结局 2/2；独立桌面 file HTML 走留下路线，390px HTTP 网站走远行路线，合计独立两结局 2/2，**不是全格式乘路线矩阵或三引擎完整验收**。每路按实际顺序读出 66 段正文，六句静音原生语音自然结束；逐项核对六个地点／人物／雨声节点，手机路线另查 390×844 与 844×390，保持设计舞台 16:9，不为填满窗口重构作者画幅。

结尾回顾、午后站台、回店看画三处均完成保存、回退、刷新及读取，正文／历史／状态／画面／雨声按上述契约恢复；两路均完成结局后回想并精确返回，随后读取通关前旧槽位，新增结局仍为 1/2。相关截图已查看。HTML／网站脚本与源工程相同，25 素材逐字节相同，36 个网站文件含 build-info.json 均经清单核对。未把静音自然结束当作听感验收。

## 当前阶段和下一步

当前是 **S0.41 技术基线上的 Web 完整作品内容打磨与发布前验收，作品候选 1.8.0**，不是技术产品版本升级或正式发行。下一批以本候选的完整阅读、演出和真实使用复核为中心，针对具体问题修改，不反复扩展无关导出选项或证明工具。16 条人工复核、25 项素材发行条件、实际主流手机／Safari、长期稳定性、获准 HTTPS 上线和离线升级整链继续开放，原生 Windows／Android 仍搁置。

现有独立收藏、已读和回想入口不自动跨版本／来源／设备迁移，旧版入口不能删；新剧情不通过“只改版本号兼容”绕过。没有设备、托管目标或发行确认依据时，保持对应项目待验，不填造通过状态。外观功能样章《给明天的回信》0.9.0 不改写，长篇剩余复制／校验成本仍参见 #373。
