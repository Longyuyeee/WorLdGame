# #311 跨结构页连续试玩

2026-10-14；起点 e27020b；开发分支 `codex/n60-e1-debugger-session`。本批完成跨页试玩与正式预览演出纠偏，沿 #304 Web-first、#306 写作连续性及 #310 接续债务；不是新发行版或最终作品验收。

## 用户流程与设计边界

作者试玩到分支或结局，需要去章节/角色/变量页校订，再返回创作。原代码卸载 App/PreviewPanel，丢失 Runtime 位置、变量、选择、History 和 Host receipts；#306 仅保留写作撤销。采用同一工程内存交接，沿正式 `updateFormalPreviewProject` 编译比较和记录输入回放，不修改 Runtime/玩家存档契约，不持久化或跨工程复活试玩。

保持兼容构建的准确位置、History 后退/未来、启动目标及诊断展开状态；显示接续提示。逻辑、变量、场景结构变化或编译失败时保留旧构建画面与诊断，并阻止旧剧情操作，要求明确重启或退出。旧启动对象已删除时明确改为从故事入口重新试玩。不能直接把当前 Story/Settings 填到旧 IR 的位置上，否则删除场景或语句会崩溃、或显示错误对白。

离开结构页之前仍必须成功保存，草稿与保存失败不绕过。切换首页/工程、刷新浏览器不恢复 Runtime。媒体随组件卸载释放并重新载入，不恢复音频/动画时钟，也不声称无缝播放；离开期间不推进剧情。结构事务撤销与写作撤销仍是独立账本。

## 实施、原始需求与实际纠偏

对齐 `03-prd.md` 3.8 的每步后退/前进与制作调试、3.10 的正式调试/源定位，`11-gal-foundation-and-automation.md` 的统一工程/预览/QA 流程，以及 #304 的持续制作完整作品要求。没有恢复原生平台主线或扩张公开部署权限。

1. `StudioContinuity` 增加同工程内存 Preview handoff；App 在持久化准备期间保留初始交接，Preview 接收后释放多余旧记录。无修改沿同构建原检查点；兼容改动沿现有正式编译/输入回放；结构或变量不兼容继续明确重启，不直接套旧 Runtime。角色/场景名称校订不丢当前路线。
2. 素材、游戏外观、检查、发布页往返同样接续；出版页的独立 Preview 不覆盖创作试玩。收起状态和 Runtime 诊断展开状态保留，首页/换工程/刷新/退出不复活。保存失败保持原页面与试玩，可重试。
3. 旧构建的 Story/Settings/Asset Index 与检查点绑定，避免删除场景或语句后索引新内容。重启要求期间禁用 Back/Forward/Continue/Step Over/Run to Cursor、旧选择和 Host 批准，旧音轨暂停，仍可退出保留编辑；原启动对象已删时明确从新入口重启。正式运行期间不允许画布点击写入旧语句。
4. 首轮快速检查到达了结局，但资源加载后的画面另有真实问题：旧正式 Preview 按当前场景文本前缀编排，不继承上一场景的角色和音乐，合法的跨场景 `hide` 被误报，音乐也可能丢失。新增 `formal-preview-stage.ts` 只投影正式 History/Host 已执行 Effect，保留跨场景演出，排除未来/未完成/取消的 Effect，Barrier 等明确批准；继续用现有视觉投影/媒体加载，不另执行剧情。单测直接重现旧文本前缀的假警告并比较修正结果。不是声称所有 Run to Cursor 临时复杂动画或长篇性能已通过。
5. 目视发现 Canvas 角色点击代理被通用按钮白底遮住立绘，恢复代理透明背景（含 hover 样式）；不改变人物构图。资源问题面板补具体诊断，避免只有“几项资源未执行”而不知道原因。
