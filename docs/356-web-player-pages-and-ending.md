# 356 · 其他游戏页面与结局自定义

2026-10-16，接续 #355。用户要求继续补齐其他部分，本批沿“进入游戏→阅读菜单→回看/保存→继续→结局→返回”扩展外观编辑。Web 优先，测试保持静音，既有未提交工作保留；未自动提交或推送。

## 已交付

在“游戏外观”新增 **其他页面** 分区，内部选择页面，避免把七组参数同时展开。覆盖阅读菜单、存读档、剧情历史、玩家设置、附加内容、制作名单、结局画面。

| 用户任务 | 当前能力 |
| --- | --- |
| 调整某一页 | 分别设置最大宽度、居中/靠右、圆角、内边距、背景不透明度、基础字号、无/渐显/上浮入场；沿用皮肤配色与字体角色 |

| 设计存档页面 | 宽屏可选一/二/三列，手机收为一列；保留手动/自动/快速/检查点/备份、分页与读档确认行为 |
| 设计结局页面 | 自定义结局引导文字、说明与返回按钮；实际结局名称继续在剧情中编辑，收藏计数与读取动作保持正式运行结果 |

当前仍是页面模板和参数编辑。没有把新增页面称作任意拖拽画布，也没有新增组件或任意动作绑定。配色来自当前皮肤，页面单独背景图片、九宫格、按钮图片/状态和自由排版仍待后续。

## 真实作者流程

在现有《给明天的回信》0.2.0 工程通过普通界面完成：

1. 进入“游戏外观→其他页面→存读档”，选择宽阔面板，宽度 1040 px、圆角 16 px、基础字号 16 px、渐显、三列；在真实预览里保存一次临时槽位，显示实际章节/片段/时间。
2. 用“统一窗体风格”应用到其余页面。结局再选紧凑卡片，560 px 宽、20 px 内边距、16 px 圆角，上浮入场。
3. 结局引导文字改为“谢谢你，读完这封回信”，说明改为“这一程已写完。愿你带着自己的答案，走向明天。也可以读取存档，看看另一种选择。”，返回按钮改为“合上信，回到封面”。
4. 应用外观并保存工程；刷新返回首页并重开后，七页设置和新文案保留。逐页实际打开桌面与手机预览，六种弹出页面的内容宽度均未超出各自容器；结局页单独查看返回入口。
5. 导出“雨夜回信·全页风格”配置，发布版本改为 **0.3.0**，下载 HTML、网页目录 ZIP 与工程 ZIP。原有三场景、46 段正文、七份素材和字体许可保持。

新参数模型位于 `web-player-screens.ts`，作为 `WebPlayerSkin.screens` 可选字段，严格检查七页、数值范围、列数与文案。不接受任意 CSS；保留 #355 原皮肤导入，新的全页配置也可导出再导入。本文所称宽度为最大宽度，较窄视口会收窄，手机优先采用安全边距和滚动布局。

## 预览隔离

新增 `appearance-preview-memory` 存档后端，供作者预览真正的空槽/保存卡片和读取操作；随 iframe 销毁，最多保留 24 个临时槽位，不使用正式 IndexedDB。没有伪造正式存档，也没有把片段预览当作完整作品试玩。

外观预览的个人设置、结局收藏和回想记录改为仅保留内存，停止写入随机预览工程的本地偏好与收藏键。预览始终静音，即使在设置页更改音量也不会改变正式游戏或其他工程。新增测试验证六个页面可打开、真实临时保存可用且不调用 `localStorage.setItem`。新项目没有正文时，其他页面仍可用明确的示例片段预览；阅读/分支预览仍提示先创作对应内容。

## 实操发现与修复

- **结局提示没有跟随自定义颜色**：原暖纸样式优先级更高，导致提示仍用紫色；补齐页面皮肤选择器优先级，实测提示为项目姓名强调色。
- **结局操作被底部快捷栏遮挡**：结局已有完整操作时收起关闭状态的快捷栏，菜单或其他页面打开时保留其窗口。桌面按钮按主要入口/次要入口分组为两列，手机单列；本样章桌面结局正文与按钮全在窗体内，返回按钮没有被裁切。
- **大窗体超过舞台高度**：结局高度同时受视口与舞台画幅限制，长内容在窗体内滚动；其他页保留各自滚动区、固定高度上限和系统安全边距。
- **原生 dialog 默认最大宽度干扰参数**：明确按视口约束窗体宽度，手机存档列数固定收为一列。
- **旧挂载测试的五项失败**：本批首次相关组中，`mount-player.test.tsx` 的五项失败；用本批修改前的 PlayerShell/Host/Mount 源码复跑同样五项失败，随后原样恢复当前文件。最终定位为测试直接调用 React 挂载 API 未包入 `act`，补齐提交等待后九项通过，没有为通过测试改正式宿主生命周期。先前进度说明中曾推测恢复扫描是原因，以本次定位为准。

## 独立目录游戏实际使用

使用实际下载包的 `preview.mjs --no-open --port=5299` 启动本机站点：

- 标题进入玩家设置，先勾选全部静音，文字立即显示，减少动效；测试期间保持。高对比开启时设置页背景为黑、标题为白，入场动画为 `none`；关闭高对比后皮肤恢复，减少动效继续用于后续操作。
- 从标题打开制作名单，确认全页风格生效、完整字体许可仍在；打开附加内容，显示真实未解锁状态。
- 开始故事，读至“你说自己只是顺路来还一把伞……”，打开阅读菜单、返回原句，进入剧情历史，查找“伞”得到一条匹配。
- 在新的三列存档页保存槽 1，继续两段、刷新，从标题读取槽 1，恢复同一句。正式存储后端为 IndexedDB，未携带编辑器预览模式；两个正在播放的测试音轨均静音。
- 经选择进入“留下的灯”，逐句走完“有人等你回来”。实际结局显示新告别文案和返回文字，收藏为 **1/2**；“查看收藏与结局”进入对应真实收藏页，返回后按“合上信，回到封面”成功回标题。
- 浏览器 warn/error 记录为空。实际游戏标签和本轮目录服务已关闭，编辑器保留可继续调整的入口。

本批独立游戏只重走这条完整路线；另一条路线在 #355 的 0.2.0 已完成，本批没有把旧结果算作 0.3.0 的 2/2。更新外观后的编辑器入口进度仍为 0/2，没有重复刷覆盖记录。没有重新做自然阅读或听感验收。
