# Web 玩家入口、存读档与离线更新

2026-10-14；起点 `3138bc6`；接续 #304/#312。

## 本批用户任务与设计

玩家从作品标题进入：看见作品介绍、开始/恢复、读取存档和设置。历史与播放速度属于阅读中工具，标题页不同时铺开。没有恢复记录时不显示冗余空状态；旧版恢复记录明确说明不能直接恢复，保留新开故事的确认和原记录。

存读档采用独立弹窗，打开时暂停剧情推进，返回回到原按钮；错误直接可见。快速保存也需要成功/失败反馈。记录显示玩家能读懂的时间与场景，存档动作不覆盖未经确认的手动槽位。原存档格式和完整校验继续使用现有实现。

沿当前 1.5.1 源工程生成 1.5.2 Web 候选，正文/分支/演出/素材不改。通过实际浏览器检查源工程、独立 HTML、目录、离线下载与断网重开、等待更新及关闭旧页面后的新版本、进度读取；平台无关，不要求指定托管服务。

## 必要验证

只跑影响到的播放器入口/菜单/存档、导出与离线相关回归、类型和 Web 构建。实际 UI 中查看桌面和手机尺寸、两路线、存读档与离线更新。记录实际失败和未跑项；不替代自然阅读定稿、真机、素材许可或公网发布。

## 结果

### 本批交付

- 标题页只保留开始、恢复/读取、设置与附加内容；历史、快进和快速存档工具在阅读时使用。没有待恢复记录时收起空恢复卡，旧构建恢复记录明确解释不能直接恢复。多语言作品仍可在标题选择语言；已有设置/附加内容返回焦点保留。作品配置了外观时不再显示开发状态、FX 或播放器水印。
- 存读档改为原生 `dialog`，桌面和手机共用独立弹窗、背景阻隔、首焦点、Tab、Escape 和返回；选择或点按底层正文不会推进剧情。手动覆盖确认继续保留。快捷保存成功有短反馈，失败直接显示对应存档页；存档消息使用可读名称，时间显示浏览器本地时间。
- 1.5.2 源工程、HTML 和目录在 `evidence/web-player-entry`。相对 1.5.1，全部 62 源条目中只有 `world.project.json` 的发布版本字段改变；正文、语句、布局、角色/变量、演出和媒体字节未改。9 场景/两结局、90 段旁白+9 句对白、9,626 字符及 71 演出沿用上一包。
- 完成真实目录离线下载、断网重开、进度读取/缓存音乐、更新等待与旧窗口关闭后启用新版、新版手动存档断网恢复、重新部署原目录后的旧快速存档回查。没有调用 skipWaiting 强制跳过玩家窗口，也没有把 HTTP 文件替换当作离线缓存更新。

### 发现与修正

1. 首轮 5 文件/101 项中 8 项旧测试依赖标题 HUD 或在存档页内点击底层选择。迁移到标题读取入口/明确返回，同时增加弹窗期间不推进的断言，原历史、分支、槽位、覆盖与恢复断言保留。
2. 新测试曾误将背景自动存档当成会将 `data-save-operation` 设为 saved，实际该标记描述显式操作；移除错误等待，继续检查快捷写入的真实反馈/失败保稿。不是产品自动存档故障。
3. 首轮实际更新证明：**1.5.1→1.5.2 即使只改发布版本，旧档也不能直接读**。工具原先等 loaded 超时，修正为检查可见拒绝、当前状态不变、旧槽位保留；没有更改 Runtime/存档身份或放宽完整校验。新版恢复卡、发布说明和离线等待提示不再无条件建议“先保存再更新”。
4. 第二轮工具记住了快速页，却假定按钮会写手动槽位，随后查手动页为空；这是工具页签假设错误。明确选择手动页，旧快速档不被覆盖，新手动档断网可读，原目录回退后旧快速档也可读。
5. 目视再检查后，去掉成品画面开发状态标记，重新构建/重导并整链复查。修正前截图和失败日志保留；`failure-editor.png` 不替代失败玩家画面，`failure-player.png` 对应工具读空手动页。

### 必要验证

最终所选 **6 文件/104 项测试通过**：PlayerShell、入口/存档、阅读、个人设置、正式导出和离线布局。日志 `regression-final.log`；媒体 play/pause 的 jsdom 未实现提示不作实际播放证据。类型检查及 Editor/Player Web 生产构建通过，保留 >500kB chunk 提示。

最终 Chromium **155.0.8059.41** 生产浏览器共 **6 组检查通过**，错误为空，见 `browser-checks.json` 和 `browser-final.log`：UI 导入/版本/三导出及源字节、桌面 HTML 留下路线、390 手机尺寸 HTTP 远行路线、旧版缓存离线重开、新版缓存等待/启用/拒绝旧档/新档离线读取、重新部署原版回查旧档。两条完整路线各 60 段旁白/6 句 TTS，等待所用语音自然结束并中途手动/快速保存、刷新、读取；原生弹窗阻隔、焦点返回和尺寸实际检查。缓存媒体以原生音轨 currentTime 推进检查，未声称全篇听感或真人阅读。

工具支持 `STUDIO_ENTRY_OFFLINE_ONLY=1` 仅复查既有产物的离线整链；必须先验证 `route-checks.json` 中三份产物摘要相同才复用路线结果。最终记录来自普通模式完整重导/整链，旧复测不累计。换机先构建 Editor，在 `apps/editor` 启动 `npx vite preview --host 127.0.0.1 --port 5194 --strictPort`，运行 `npm run audit:web-player-entry:browser`；可指定 `STUDIO_UI_URL`/`STUDIO_CHROME`。

未跑：全仓/全部 Editor/完整 check、全部历史 golden、其他浏览器引擎、真机、长期运行/旧长帧、自然阅读和配音听感、素材授权或实际公网。桌面浏览器的手机尺寸不替代物理设备。

### 接续

存档跨构建迁移仍未实现；发布者要先检查兼容并提供原版入口，不能承诺修改版本后可继续读取。浏览器不会自己提供原版切换，本轮回退由测试服务重新部署原包，再按正常更新激活。后续优先设计安全的存档更新兼容/恢复路径，继续作品自然节奏、真机与来源定稿；原生平台保持搁置。
