# 产品需求文档（PRD）

## 1. 范围定义

本文描述最终产品能力，并使用优先级控制落地：

- **P0**：没有它就无法验证核心定位。
- **P1**：生产版不可缺少，但可在技术预览后补齐。
- **P2**：生态、团队和差异化增强。

## 2. 端到端主流程

1. 创建或导入项目。
2. 选择模板与设计分辨率。
3. 建立角色、背景、音频和字体资源。
4. 在 Sequence 或 Script 写对白与演出。
5. 在 Route Map 连接场景和结局。
6. 在 Stage 调整角色、镜头和 UI。
7. 即时预览并从任意节点运行。
8. 使用 Debugger/Story QA 修复逻辑、资源和本地化问题。
9. 选择平台与构建配置。
10. 生成、签名、测试并发布。

## 3. 功能模块

### 3.1 项目与工作区

#### P0

- 新建、打开、最近项目和示例项目；
- 本地自动保存、崩溃恢复和手动快照；
- 章节/场景目录；
- 全局搜索对白、节点、变量、角色、资源和标签；
- 可停靠桌面工作区；
- 手机任务模式和底部导航；
- 工程完整导入/导出；
- 离线打开和编辑。

#### P1

- 项目模板、模块模板、场景模板；
- 批量重命名和语义引用更新；
- 资源使用位置和孤立资源；
- 项目健康总览。

#### P2

- 云项目、版本历史、跨设备同步；
- 多项目共享资源库；
- 组织模板和权限策略。

### 3.2 Route Map

#### P0

- 章节、场景、标签和结局节点；
- 选择与条件连线；
- 分组、折叠、搜索、过滤和局部加载；
- 跳转目标自动补全；
- 不可达、悬空和循环提示；
- 高亮从入口到指定结局的路线；
- 双击进入场景 Sequence。

#### P1

- 自动布局与手动布局并存；
- 按角色、变量、完成状态或测试覆盖过滤；
- 路线比较；
- 场景摘要和预估时长；
- 章节/路线导出为图片或评审链接。

#### P2

- 故事状态空间可视化；
- Storylet/Saliency 视图；
- 大型图多级聚合和统计热图。

### 3.3 Sequence

场景内部的主要可视化编辑方式。

#### P0

- 对白、旁白、背景、角色、表情、音频、选择、变量、条件、跳转、等待和结束块；
- 拖动排序、复制、批量选择和折叠；
- 插入命令搜索与快捷键；
- 当前运行块高亮；
- 每个块显示最关键参数，详细参数进入 Inspector；
- 一键在 Script/Stage 中定位同一语义节点。

#### P1

- 摄像机、转场、视频、滤镜、动画轨道；
- 宏/片段/可复用子流程；
- 批量对白与表格模式；
- 语音波形和文本时长参考；
- 时间标尺和并行演出轨道。

#### P2

- 可视化自定义命令组合；
- 高级动画曲线；
- 外部时间线/视频工具交换格式。

### 3.4 Script

#### P0

- 语法高亮、补全、诊断、跳转定义、查找引用；
- 文本、选项、变量、条件、命令、标签和注释；
- 稳定语句/文本 ID 的弱显示，不干扰写作；
- 格式化和安全重构；
- 与 Sequence 双向即时同步；
- 外部编辑后增量解析与冲突提示。

#### P1

- 多光标、代码片段、项目范围替换；
- 命令文档悬浮提示；
- 变量类型推断；
- 导入 Yarn、ink、Ren'Py/WebGAL 的受支持子集。

#### P2

- Language Server；
- VS Code/其他编辑器官方扩展；
- 自定义语法包。

### 3.5 Stage 与 UI Composer

#### P0

- 设计画布、设备比例和安全区；
- 背景、角色和 UI 实时预览；
- 角色位置、缩放、旋转、锚点和层级；
- 常用进入/退出/移动预设；
- ADV、NVL、气泡三种文本模板；
- 手机触控目标和横竖屏预览。
- 摄像机、角色、背景、音频和特效的基础多轨时间线；
- 关键帧、常用缓动和运动轨迹预览；
- Stage、Sequence 与当前运行语句实时同步。

#### P1

- 标题、对话、选择、历史、存档、设置、鉴赏、音乐室可视化主题编辑；
- 响应式约束、字体样式和设计 Token；
- 摄像机、转场、粒子和滤镜；
- 角色分层表情、口型、眨眼；
- Live2D/Spine 官方适配插件。
- 多轨音频波形、节拍/事件标记和语音对齐；
- 镜头、运动、转场和音频可复用预设；
- 遮罩、序列帧、颜色分级和高级屏幕特效；
- 关键帧曲线编辑、批量偏移和片段复用。

#### P2

- UI 组件市场；
- 主题继承和多品牌模式；
- 3D 场景/角色插件。

### 3.6 视觉系统、动效与工作模式

#### P0

- 现代多彩的语义色系统和设计 Token；
- Writer、Director、Flow、Production、Debug & QA、Mobile Focus、Quick Start 七种工作模式入口；
- Beginner/Pro 默认布局可无损切换；
- Route、Sequence、Script、Stage 和 Debugger 对相同语义使用一致颜色与图标；
- 当前执行、跨视图定位、拖动吸附、保存和构建拥有连续动效反馈；
- 关键交互目标 60 FPS，动画不阻塞输入、撤销、保存和上下文切换；
- 完整、简化、减少动效三级设置；
- 状态同时使用颜色、文字、图标或形状表达。

#### P1

- 工作区布局、面板、快捷键和强调色可保存为个人配置；
- 变量传播、路线覆盖和 QA 影响范围的动态图解；
- 高刷新率设备适配和低性能设备自动降级；
- Production 模式支持类电子表格批量编辑、过滤、粘贴、状态列和审阅；
- Director 模式支持多轨时间线、曲线、波形、镜头和音画同步；
- 团队主题包和编辑器浅色主题。

#### P2

- 可安装工作区与动效主题；
- 专业设备控制面板和自定义工作流模式；
- 团队级布局策略与角色预设。

## 4. P0 纵向切片验收

技术预览必须用同一个示例项目证明：

1. Windows 与 Android 手机都能打开工程；
2. 两端都能添加对白、修改角色、建立选择和条件；
3. Route Map、Sequence、Script、Stage 显示的是同一内容；
4. 任一视图修改后，其他视图在 500 ms 内同步；
5. 可从任意语句预览，并查看当前变量；
6. 检出一个不可达结局和一个缺失资源；
7. Web 和 Windows 产物运行到相同结局，保存/回滚结果一致；
8. 工程导出后可在无账户、离线环境重新打开；
9. 崩溃后恢复到最近自动保存点；
10. 所有关键操作可仅用键盘完成，手机拖拽均有替代入口。
11. Writer、Director、Flow、Production、Debug & QA、Mobile Focus、Quick Start 均能定位并修改同一条测试语句；
12. Route 追踪、跨视图定位、Stage 操控和预览同步的动效不阻塞输入，并有减少动效版本；
13. 示例场景至少包含一次镜头关键帧、角色运动、转场和 BGM/Voice/SFX 同步；
14. 编辑器及 Web/Windows 玩家包在目标设备的关键流程达到已批准的帧时间预算。

## 5. 明确排除

技术预览不以以下内容作为完成条件：

- AI 写作；
- Live2D/Spine；
- 实时协作；
- iOS 商店提交；
- 插件市场；
- 3D；
- 商业支付。

它们不能阻塞对核心数据模型、跨端编辑和发布路径的验证。
