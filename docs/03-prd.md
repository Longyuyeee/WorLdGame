# 产品需求文档（PRD）

## 1. 范围定义

本文描述最终产品能力，并使用优先级控制落地：

- **P0**：M1 首个正式发布版本不可缺少。
- **P1**：M1 正式发布后的规模化生产、平台和工作流增强。
- **P2**：生态、团队和差异化增强。

当前只承诺交付 P0/M1，且 M1 是首个可正式公开发布的 Stable 版本。P1、P2 和 M2 以后内容是未排期愿景池；账户、云同步、云构建和 iOS 当前均不实施。

## 2. 端到端主流程

1. 创建或导入项目。
2. 选择模板与设计分辨率。
3. 建立角色、背景、音频和字体资源。
4. 在 Sequence 或 Script 写对白与演出。
5. 在 Route Map 连接场景和结局。
6. 在 Stage 调整角色、镜头和 UI。
7. 即时预览并从任意节点运行。
8. 使用 Debugger/Story QA 修复逻辑、资源和本地化问题。
9. 选择平台与构建配置。
10. 生成、签名、测试并发布。

## 4. P0 纵向切片验收

M1 Stable 候选必须用同一个示例项目和正式构建链证明：

1. Windows 与 Android 手机都能打开工程；
2. 两端都能添加对白、修改角色、建立选择和条件；
3. Route Map、Sequence、Script、Stage 显示的是同一内容；
4. 任一视图修改后，其他视图在 500 ms 内同步；
5. 可从任意语句预览，并查看当前变量；
6. 检出一个不可达结局和一个缺失资源；
7. Web、Windows 和 Android 产物运行到相同结局，保存/回滚结果一致；
8. 工程导出后可在无账户、离线环境重新打开；
9. 崩溃后恢复到最近自动保存点；
10. 所有关键操作可仅用键盘完成，手机拖拽均有替代入口。
11. Writer、Director、Flow、Production、Debug & QA、Mobile Focus、Quick Start 均能定位并修改同一条测试语句；
12. Route 追踪、跨视图定位、Stage 操控和预览同步的动效不阻塞输入，并有减少动效版本；
13. 示例场景至少包含一次镜头关键帧、角色运动、转场和 BGM/Voice/SFX 同步；
14. 编辑器及 Web/Windows/Android 玩家包在目标设备的关键流程达到已批准的帧时间预算。
15. 玩家能分别设置自动播放与快进速度，并验证四种快进模式不会漏执行状态命令；
16. 每句对白可后退和前进，改变历史选择后旧前进分支被正确截断；
17. 同一脚本能自动生成创作者 Route Map，无需手工维护连接副本；
18. 示例项目能自动生成 CG 画廊、Scene Replay、Music Room 和 Ending 页面；
19. Gal 配置中心覆盖文本、推进、保存、音画、输入、路线和附加系统的 P0 设置；
20. 自动生成页面和回滚/前进状态在 Web、Windows 与 Android 上结果一致。
21. Optimization Center 能显示下载、安装、系统/GPU 内存、加载和帧时间预算，而非只有源文件大小；
22. Safe Auto 不修改源素材，所有派生产物删除后可重建且优化可回退；
23. Golden Dicing 至少覆盖相似 CG/立绘差分、透明立绘和无收益背景；无损重建逐像素一致，三端无接缝，报告同时显示体积、内存、Atlas、Draw Call 和加载收益；
24. 示例项目在目标低内存档连续运行两小时无崩溃、OOM 或持续内存增长；
25. 弱网中断、损坏资源包和磁盘不足不会破坏最后一个可运行版本或有效存档；
26. 使用编辑器完成一部 20–30 分钟的原创校园短篇，并成功生成可正式分发的 Web、Windows、Android 包；三端固定路线状态一致；
27. Windows 与 Android 编辑器 Stable 安装包通过安装、升级、卸载、签名/哈希、许可证/隐私、第三方声明、回退和 Release Assurance 审核。

## 5. 明确排除

M1 首个正式版不以以下内容作为完成条件：

- AI 写作；
- Live2D/Spine；
- 实时协作；
- iOS 商店提交；
- 插件市场；
- 3D；
- 商业支付。

应用商店自动提交不属于 M1，但人工正式发布所需的签名产物、元数据、合规清单和可验证发布证据属于 M1。

它们不能阻塞对核心数据模型、跨端编辑和发布路径的验证。
