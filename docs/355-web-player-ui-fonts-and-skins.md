# 355 · 标题、阅读界面、字体与皮肤

2026-10-16，接续 #354 的实际工作区。按普通作者的顺序完成第一批外观自定义，并补窗口、文字与按钮动效预设。Web 优先，测试保持静音；既有未提交工作保留，本轮未自动提交或推送。

## 本轮可直接使用的能力

入口为项目左侧“游戏外观”。分为标题画面、阅读与选项、字体、皮肤与动效四页，参数在单独的滚动区内，右侧使用正式 Player 预览。可放大预览、切换桌面/手机尺寸和标题/对白/选项，重播查看效果。

| 作者任务 | 已实现的范围 |
| --- | --- |
| 改标题 | 自选封面、全舞台/卡片内展示、左/中/右对齐、标题区宽度、字号、窗体与封面透明度、开始文字和按钮圆角；简介保留原入口 |
| 改阅读与选择 | 对白框底/中/上位置、宽度、底色透明度、圆角、内边距、背景图片；正文/姓名字号、行高、字距、选项圆角和纵排/宽屏双列。手机优先采用阅读安全布局，顶部/中央定位仅作用于桌面 |
| 使用自己的字体 | 从页面直接打开现有素材库导入，回来后选择正文、标题、姓名、按钮/菜单四种字体角色；支持系统黑体/宋体和已检查的 WOFF/WOFF2/TTF/OTF，单字体上限 32 MB。角色继承、自动项目字体与字体加载失败回退保留 |
| 做自己的皮肤 | 月夜剧场、纸上来信、海风书签三个起点；八类自选颜色，色板和十六进制输入；可继续改参数、撤销/重做和恢复默认 |
| 复用皮肤配置 | 导出/导入 `.worldskin.json`，按文件摘要对应素材，跨工程相同文件可匹配不同素材 ID；同 ID 不同摘要不会被当作同一素材。缺素材时明确列名并禁止应用，作者可去对应页重新选择 |
| 第一批动效 | 标题和对白窗体的无/渐显/上浮，文字墨迹渐清，按钮无/轻抬/柔光；窗口/文字动效时长 100–1600 ms。作品、系统和个人减少动效设置优先生效 |
| 保存和交付 | 草稿预览→应用玩家外观→保存工程→发布。草稿保护沿用页面离开拦截，未应用时禁用保存工程；参数进入源工程及两种正式游戏导出 |

皮肤配置只包含参数和素材对应关系，**不包含图片或字体字节**；界面已说明需先导入相应文件。当前是可调整的标题与阅读模板，还没有任意拖动组件、添加按钮或绑定新动作的画布，也没有各页面完整的组件编辑器。

## 普通作者实际操作结果

沿用 #354 从空白创作的《给明天的回信》，通过正常界面完成：

1. 在标题页填写新开始按钮文字，再从字体页打开素材库导入 `assets/skin-demo/letter-demo.woff2`，命名“文楷·回信字集”；回到外观页，标题草稿仍在，新字体可直接选择。
2. 正文/标题选择该字体，姓名选择系统黑体，按钮跟随正文。标题改全舞台封面、左对齐、72 px、66% 宽、窗体 50%、封面 80%，开始按钮为“打开这封回信”。阅读改 24 px、12 px 圆角和宽屏双列选项。
3. 选择内置皮肤后撤销，恢复前一草稿。填写深青底色、暖白正文、金色强调等八种颜色，配置渐显/上浮/墨迹/柔光和 450 ms，应用后保存。刷新返回首页、重开，实际参数、图片、字体和简介保留。
4. 实际导出“雨夜回信·文楷”皮肤配置。导入故意不匹配的字体摘要时提示“文楷·回信字集”缺失、应用不可用；放弃后导入有效配置，颜色/字体对应正确。导入不会替换当前作品标题与简介。
5. 在实际 Player 内查看桌面标题、390×740 手机对白和桌面两列选择，手机没有横向溢出，字体状态显示已加载。预览使用作品片段并剔除声音，不接正式存档库，不计入作品结局试玩。
6. 发布版本改为 **0.2.0**，制作名单加入字体来源和完整 OFL 文本，来源台账记录版本、摘要及子集事实；没有把整个作品的发行条件改为通过。保存并下载 HTML、网页目录 ZIP、工程 ZIP。

最终样章仍为三场景、46 段正文、一个选择和两个结局；原有三个脚本与 0.1.0 字节一致。新增一份字体，共七项素材。《雨停之前》1.7.14 保持原候选。

## 实操中修复的问题

- **新字体导入后难以继续外观编辑**：接通外观页素材库入口，并同步新增资产元数据，保留未应用的标题/字体草稿。
- **精确颜色输入不便**：补色板旁的颜色值输入；通过真实 Player 的计算样式确认实际生效。本机 UI 自动化直接填原生颜色控件未触发 React 修改，因此真实配色通过新增文本框完成，不将原先未生效操作记为成功。
- **标题出现多余滚动条、字号被压小**：标题原固定 640 px 最小高度改为受视口约束；作者字号在桌面实际生效，窄屏才限制。960×620 标题页实测文档高度等于视口 620 px，标题为 72 px。
- **分支片段无法启动**：初版将选择指回预览入口，正式编译器报 `NO_REACHABLE_ENDING`。修为独立结束场景，真实 Player 已能显示两个选项；新增正式编译与两个选项到达预览结局的回归。
- **预览与交付容易不一致**：没有修改的旧工程沿用旧 Player 外观，不因打开编辑页就加皮肤；新样式使用同一份正式 Player/CSS。自动项目字体的预览也提供字体源，由 Player 执行原语言匹配。
- **放大预览在矮窗口超出屏幕**：缩放同时受宽、高约束，保留关闭和设备切换控件；手机/桌面使用各自真实 iframe 尺寸。

## 字体与当前边界

示例来自官方 LXGW WenKai Lite v1.522 Regular，来源与摘要在 `assets/skin-demo/source.json`。保存原 OFL 文本；通过 `tools/build-skin-demo-font.py` 生成 110,992 字节的 WOFF2 子集，请求 559 字符。它用于本短篇验证，其余字符继续使用系统回退，不是覆盖所有中文的完整字体。完整许可已进入源工程/玩家名单和目录 `credits.txt`。

七项素材在现有发行准备系统中仍为待处理。字体记录了事实与依据，没有自动替所有者确认发行条件；原六项图片/音乐的许可缺口仍在。测试全程静音，不计声音听感通过。浏览器此前禁止 `file://`，本批单文件 HTML 已生成和核对内容，未直接双击运行；独立运行证据来自目录包正常 HTTP 入口。

首批实测字体为 WOFF2；其他字体格式、字体独立加载失败提示、复杂字库/多语言组合、NVL/Bubble 与所有极端参数组合未逐项实测。手机为浏览器尺寸预览，不是真机/Safari。高对比和减少动效有样式/定向测试保护，没有重新执行全部无障碍人工验收。
