# S0.40 当前场景搜索与窗口感知跳转审计

## 阶段目标与边界

S0.40 解决 10,000 步场景不能依赖翻阅 157 个渲染窗口定位内容的问题。Writer 新增常驻搜索入口，可按一步起算的步骤号、`Statement ID`、关联稳定 ID 或可见文本定位，并把命中项同步为当前选择、切换 64 步窗口、将键盘焦点移到真实剧情卡片。

本阶段只搜索当前场景最后一次成功提交的 Canonical 投影；不建立全工程数据库索引，不搜索资源、变量或跨场景引用，不改变源命令，不实现跨窗口拖放，也不修改 project schema。搜索词、当前结果和焦点意图均为会话临时状态，不进入保存、WAL 或 Undo。

## 冻结查询契约

- 空白查询不匹配任何内容，也不自动选中第一步。
- 纯数字和 `#数字` 严格解释为一步起算的步骤号；`0`、越界值和非法安全整数返回空结果，不退化成模糊文本查询。
- 文本使用 Unicode NFKC、去除首尾空白并转小写，确保全角输入和稳定 ID 大小写行为一致。
- 排序固定为：Statement ID 精确、Statement ID 前缀、关联 ID 精确、关联 ID 前缀、Statement ID 包含、关联 ID 包含、展示文本前缀、展示文本包含；同等级保持场景顺序。
- 关联 ID 包括对白 `textId`/`speakerId` 与选项 ID/目标场景 ID；文本包括对白、演出摘要/命令、选择提示/选项和结局名。
- 结果总数完整计算，DOM 最多挂载前 50 项并明确提示截断，避免高频词恢复线性 DOM。

## Canonical 草稿隔离与索引更新

索引由 `scene.statements` 的已提交投影通过 `useMemo` 派生；有效 Script 提交、Writer Patch、插入、删除、移动或 Undo/Redo 产生新投影后自动重建。无效 Script 草稿保留在独立 Source Draft 中，Writer 仍读取旧投影，因此搜索结果不会包含未提交或不可解析文本。界面在存在草稿时显式说明这一点。

索引是可随时重建的派生内存，不进入 `ProjectSnapshot`，因此 schema 继续为 v2。搜索与跳转本身不派发写命令，浏览器证据确认 revision 保持 `r0`。

## 跳转、窗口、拖放与焦点

- 点击结果、提交表单或使用上/下一个结果都会派发既有 `select-statement`，并通过 `revealStageIndex` 切换到包含命中的 64 步页。
- React 挂载目标卡片后，焦点按稳定 DOM ID 移到该卡片；不会把焦点留在已经失去语义上下文的结果按钮。
- Arrow Up/Down 循环结果，Escape 清空搜索；按钮和 `aria-live` 状态为触屏与辅助技术提供等价路径。
- 拖动 Cue 时禁用结果、导航和提交，避免跳转卸载正在拖动的源节点。搜索不会改变批量选择集合。
- 切换场景清空搜索、结果位置与待处理焦点，避免把旧场景稳定 ID 应用到新场景。

## 响应式与可访问性

桌面入口使用单行搜索、结果状态和三键导航；390×844 手机视口改为两列结构，输入框独占整行。浏览器测量确认输入高 42 px、上一个/跳转/下一个按钮均为 44×44 px、结果区上限 224 px，页面没有横向溢出。结果使用 `listbox/option` 与 `aria-selected`，状态使用 polite live region。

## 验证证据

- 定向回归覆盖步骤号、Statement ID、关联 ID、中文文本、选择选项、空查询、越界数字、排序、50 项截断、总数、真实卡片焦点和 revision 不变。
- `npm run check` 全量通过：48 个测试文件、316 项测试、TypeScript、生产构建、34 个可移植文件/3 个 Node adapter 架构边界及全部脚本/素材性能门。
- 10,000 步性能门分别冻结索引构建小于 300 ms、连续三类查询小于 100 ms；本次实测为 22.56 ms 与 9.68 ms，步骤 9744 的文本、稳定 ID 和步骤号均定位到索引 9743。
- 真实 Chromium 验证“广播站”得到 `1 / 1 项`，点击后焦点为 `statement-card-stmt_gate_001`，窗口仍为 `1–4 / 4`，revision 为 `r0`，Preview 默认仍是 1920×1080。
- schema、Canonical Script、Preview 数据源、已有 64 步 DOM 上限和拖放边界均未改变。

## 下一阶段入口

S0.41 应先审计跨场景全局搜索的索引生命周期、增量失效、场景分组、结果虚拟化和定位后的场景切换事务，再决定是否引入 Worker 或本地持久索引。资源、变量、引用和语义重构仍需分别定义类型化结果与权限边界，不能简单扩张为字符串扫描。
