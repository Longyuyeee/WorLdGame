# Web 完整剧情与演出制作包

日期：2026-10-13。接续 dc5e9fb、#304/#306。

## 实施前用户任务与交付范围

沿同一《雨停之前》工程扩展公共剧情和两条路线，增加候车室/站台的铺垫、留下后的夜灯与天明、远行后的车窗与重逢。交付有起承转合的多场景作品、可编辑源工程、HTML 和本地 HTTP 目录包。根据实际源文本统计每条路线篇幅，记录估算依据；人工阅读时长和公网仍待独立验收。

从作者视角补齐制作阻碍：多行文字可在写作页一次插入为旁白/指定角色对白，预览句数与字数，一次撤销/重做，未提交输入有取消/放弃保护；插入在结局前，不要求作者编辑技术 ID。素材详情可主动试听音频；角色位置和音乐音量在添加演出时即可选择，音轨使用中文名称。保留参数草稿、错误保存、素材原子写和历史来源。

新增原始立绘/店内背景通过内置 imagegen 生成，保留透明度与生成说明；音乐/雨声/提示音通过项目脚本生成并保留音源。已有车站背景保持测试素材标识。所有素材经过真实导入、选择、预览、保存和导出，不直接改存储 Script/IR 生产验收工程。

整包验证覆盖批量文字原子性/字面文本/草稿、音频试听释放、演出参数，两条路线的背景/立绘/音频、跨场景、存读档/刷新、保存重开、窄屏以及目录子路径部署。适量相关回归、类型/双构建/静态审计完成后记录实际问题、未跑项、产物与接续，提交推送。

## 完成的产品与作品内容

同一《雨停之前》工程发展为 1.2.0 剧情候选：9 场景、2 角色、2 结局、90 段旁白和 9 句角色对白，共 9,544 个正文字符、143 步，其中 35 个演出步骤。数量从界面导出的实际 Script JSON 复核，不直接改 Script/IR 或浏览器存储制作工程。

公共路线：车站的雨 → 候车室的旧信 → 站台前的约定。

- 留下：留下 → 灯下的回信 → 雨后的天明 → 同行的约定。
- 远行：远行 → 车窗与海 → 再一次见面 → 远行的约定。

公共剧情补足旧信、双方各自的计划与明确约定；留下路线包含回信和行动，远行路线包含新城市、不顺利的沟通和重逢。两种选择不是正确/错误答案。每条路线 60 段正文及 6 句对白；旁白部分分别为 6,330 / 6,354 字。按 250–350 字/分钟，仅正文预算约 18–25 分钟；这不是人工实测，不能据此关闭建议 20–30 分钟或完整作品最终验收。

新增 6 项素材：小夏透明立绘、雨夜面馆、雨后海边、原创合成背景音乐、雨声与进站提示音。与已有车站测试背景合计 7 项素材。使用实际导入、检查、选择及源文件导出。新增图片由内置 imagegen 技能生成，音频保留可复现原始合成脚本，提示词/制作要求、透明度和来源见 `assets/rain-story/README.md`；没有录制配音，不能称真人配音完成。原车站仍是测试背景，不能把整个工程默认当成授权已确认的公开发行作品。

演出包括左右站位、背景淡入、循环音乐/雨声、进站提示音、离开车站后隐藏小夏、进入面馆降低雨声音量、天明路线转到海边，以及结局前停止所有音轨。故事内时间蒙太奇仍复用部分背景；家中/列车/候车室专属背景、表情变化与配音属于下一批内容精修，当前不是每个叙述地点都有专属美术的最终演出版本。

作者现在可在写作标题旁“添加成段文字”：每个非空行成为一句，可选旁白或指定角色，显示句数和字符数，一次加入/撤销整批，自动选中最后一句便于接着写。限制 1–50 行、总 32,768 字符、每句 2,000 字符；旁白按字面编码，不将脚本样式文字变成命令。对白含脚本元标记则提示删除或改旁白。Escape 保留未提交文字，明确放弃才关闭；事务拒绝也保留整个草稿。弹窗打开时不响应底层新增演出和插入快捷键。

音频详情和添加演出均可主动试听，不自动播放、不修改剧情音乐；检查失败/缺失/不完整内容提示重试，16 MiB 以内验证字节数与 digest，退出暂停并释放 URL，迟到读取不复活旧控件。添加角色可选左/中/右，添加音频可选中文音轨、循环及 0–1 音量（最多三位小数），简写 `.3` 等规范化成正式源格式。

## 实际任务发现的问题与纠偏

1. 初次批量加入后仍选旧步骤，后续跳转被插到正文前。仅“到达结局”的检查曾误以为完整流程通过。修复加入后选末句，追加导出源顺序断言与每条路线 **60 段实际呈现** 断言，不再只看最后的结局。通用撤销/重做保留仍有效的当前选择，不承诺历史光标；撤销后重做整批时，继续写作前可重新选末句。
2. 添加音量控件允许 `.3`，旧结构事务只接受带前导数字的值，初次音乐没有加入。修复规范化、千分精度和明确错误，实际检查每次添加演出后步骤数增加；不能只以弹窗关闭推定写入成功。
3. 正式玩家忽略 `position=left/right`，与作者预览默认位置不同。Player presentation 采用相同 20%/50%/80% 默认值，显式 x 仍优先；不改 Runtime/hash/存档格式。
4. 在旁白后添加/移动演出时报找不到锚点。旧结构 Patch 的 ID 查找漏了旁白和其他 P0 步骤，补齐稳定 ID，并在唯一性检查保留旁白 textId；仍保留注释归属和结局边界拒绝，不通过重排源稿绕开错误。
5. 手机截图发现横屏比例舞台裁掉长旁白开头；旧“按钮在视口内”检查没有发现父级裁切。竖屏手机改为足够高的阅读舞台，限制文字框并提供内部滚动，给存档操作留空；检测同时约束视口和舞台。单文件 HTML 版本条原来额外占用视口高度，补上固定 24px 占位预算，防止正文与底部操作重叠。目录和未带版本条的嵌入保持零偏移。

验证工具初次错用“修改角色”而实际入口为“编辑角色”；媒体检查初次只认 img，忽略正式 Canvas 采样；制作中开发服务器热重载使发布页返回首页。分别修正控件入口、等待真实 Canvas ready，并改用生产 Editor preview 完整重跑。失败未当成产品通过；裁切前截图单独保留为 `review-before-mobile-clipping.png`。jsdom 的未实现媒体日志不当成真实播放验收。

## 验证结论

最终相关回归 **20 文件/191 项通过**，包含正文批次、草稿/拒绝保稿、试听释放、P0 锚点与源事务、Compiler、编辑器预览/导出/连续性、玩家媒体与站位。随后补明确旁白可访问名，3 文件/13 项复测通过（与 191 重叠，不累加）；最终 typecheck 和 Editor 构建通过，Player 构建已在同一 Runtime/CSS 版本通过。架构、需求、工作区和整合基线通过。Editor 仍有既有大 chunk 提示。

生产 Editor preview 下完整浏览器流程 **11 组通过**（其中两组分别为 HTML/HTTP 的保存刷新读取），异常为空。HTML 桌面留下、390 远行及真实 HTTP `/gal/` 留下各实际呈现全部 60 段正文、经过预期六场景并抵达对应结局；音乐/雨声实际 currentTime 推进、提示音播放、左右位置、Canvas 解码、结局音轨清理和 source transfer 顺序均检查。mid-story quick save / refresh / load 的 state hash 一致并恢复音乐。

独立 **4 项阅读/创作回查通过**：320 和 390 的首段正文完整位于舞台/视口内、不覆盖上下操作；320 成段文字弹窗及放弃/旁白控件可达；隔离工程通过 UI 加入 1,400 字段落并正式导出，320 内部滚动能抵达最后一行且不推进 Runtime。该压力导出仅为临时验证，不替换正式故事工程。截图目视核对，裁切前/后分开保留。320 长段正文会遮住部分立绘，仍是后续窄屏演出精修项，不称所有手机布局完美。

压力截图最后发现最大高度文字框仍可能碰到 320 下换行的工具区，增加窄屏顶部留空，最终重新通过发布 UI 导出 HTML/目录，再复跑上述 4 项。`artifact-refresh.json` 确认相对 11 组完整流程的产物，Canonical/全部媒体载荷及 Runtime JavaScript 完全相同，仅 CSS 阅读高度调整；没有重跑此最后 CSS 下的全部三条完整游玩，不能把 11 组说成最终 CSS 的全流程重测。最终类型和双构建通过。

未跑全仓库/完整 check、全部 golden、Runtime 大规模种子回放、两小时游玩、旧长帧预算、跨浏览器/物理手机/旋转/IME，未部署公网或宣称远端 CI 绿色。此次作品为连贯剧情候选，`fullLengthWork` 与人工计时仍为 false。
