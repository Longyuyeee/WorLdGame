# Gal 基础系统与自动化生产规格

## 1. 已确认范围

以下能力属于产品必备范围：

1. 覆盖商业 Galgame 常见系统的基础配置；
2. 自动分析相似立绘与 CG，通过切块、去重、图集和平台压缩降低容量；
3. 玩家可调整快进速度和快进规则；
4. 玩家与调试器均可按每句对话或每个剧情步骤后退、前进；
5. 从故事模型自动生成创作者路线图、玩家流程图、CG 画廊、场景回想、音乐室和结局列表。

这些能力必须集成在统一工程、预览、QA 和构建流程中，不能要求普通创作者修改代码或手工维护重复数据。

容量、加载、内存和长期稳定性的横向规则见[《容量、性能与运行稳定性优化规格》](12-size-performance-stability.md)。

## 2. Gal 基础配置中心

“包含全部基础配置”不能依赖一张不断膨胀的表单。编辑器提供可搜索的 Project Settings，并按 Basic/Advanced 分层；每一项都支持默认值、说明、恢复、实时预览和平台覆盖值。

### 2.1 项目与显示

- 设计分辨率、宽高比、横竖屏、窗口/全屏、刘海与安全区；
- 目标帧率、渲染比例、色彩空间、图片质量和低性能设备档位；
- 默认语言、支持语言、地区、时区和内容分级信息；
- 启动画面、标题、应用图标、包名、版本号和版权信息；
- Windows、Web、Android、iOS 分平台覆盖值；
- 调试、预览、测试、正式四套配置 Profile。

### 2.2 文本与消息窗口

- ADV、NVL、气泡、全屏文本和多消息窗口；
- 角色名、正文、旁白、内心、系统文字和强调文字样式；
- 字体、语言字体回退、字号、行距、字距、边距和阴影/描边；
- CJK 禁则、标点策略、Ruby/注音、富文本、Emoji 和纵排扩展点；
- 每字显示速度、瞬间显示、点击补全文本和翻页/换行规则；
- 已读/未读视觉标记、等待光标、角色头像和语音播放状态；
- 文本框透明度、位置、自动隐藏和演出时隐藏规则。

### 2.3 推进、自动播放与快进

- 普通推进输入：鼠标、键盘、触摸和手柄映射；
- 自动播放等待时间、按字符数追加时间、语音结束后等待时间；
- 快进目标速度、按住临时快进、切换持续快进；
- 只跳过已读/允许跳过未读；
- 快进时是否播放语音、是否等待转场、是否跳过视频；
- 遇到选择、未读重要提示、章节边界和错误时强制停止；
- Editor Preview 独立的 0.5×、1×、2×、4×、无限速测试倍率。

### 2.4 保存、读取与历史

- 手动存档、自动存档、快速存档、检查点和云存档开关；
- 存档槽数量、分页、截图、时间、章节、路线和自定义元数据；
- 历史记录长度、语音重播、跳回该句和复制文本策略；
- 每句/每步回滚深度、前进历史长度和不可逆命令策略；
- 存档版本、迁移、损坏恢复和跨平台同步冲突策略；
- 已读、CG 解锁、结局、成就等持久元状态是否受回滚影响。

默认建议：剧情变量和舞台状态参与回滚；已读、CG/结局解锁等元进度不因回滚撤销，但项目可覆盖。

### 2.5 画面与演出

- 背景、前景、CG、角色、表情、服装、道具、UI、字幕和特效层；
- 角色锚点、站位、缩放、旋转、透明度、混合模式和遮挡顺序；
- 摄像机、转场、震动、遮罩、滤镜、粒子、序列帧和视频；
- 默认进出场时长、缓动、镜头预设和演出宏；
- 立绘分层、口型、眨眼及 Live2D/Spine 插件配置；
- 闪光、剧烈位移和高频震动的无障碍替代方案。

### 2.6 音频与语音

- Master、BGM、Voice、SFX、Ambient、UI 六类音量；
- 声道静音、声像、循环、淡入淡出、ducking 和响度目标；
- 单角色语音开关、语音重播、跨句续播和点击时截断策略；
- 自动播放等待语音、快进时的语音策略；
- 文本 ID 到多语言语音文件的映射、缺失和错位检查；
- 蓝牙/耳机切换、失焦静音和移动端音频中断恢复。

### 2.7 选择、路线与状态

- 选项样式、倒计时、默认选项、禁用/隐藏条件和已选标记；
- 变量类型、默认值、作用域、持久化和调试可见性；
- 章节、场景、标签、跳转、调用、返回、结局和路线命名；
- 随机种子、条件表达式、成就和解锁条件；
- 玩家流程图的剧透策略、未知节点样式和完成率规则。

### 2.8 玩家 UI 与附加系统

- 标题、继续、章节选择、主菜单、暂停、帮助、确认和退出；
- 设置、历史、存档、读档、快速保存/读取；
- CG 画廊、场景回想、音乐室、结局、人物资料和术语表；
- 通知、Tips、内容警告、制作人员名单和许可证；
- 新内容标记、解锁动画、完成率和隐藏项目显示策略；
- 主题 Token、响应式布局和桌面/手机输入提示。

### 2.9 本地化、无障碍与发布

- 语言切换、语言专用字体/图片/语音/视频、文本扩展预算；
- 字幕、自述、Alt 文本、高对比度、大字体、减少动效和减少闪烁；
- 按键重映射、长按替代、自动推进和操作超时设置；
- 资源分包、首包、章节下载、补丁、缓存和离线策略；
- 平台签名、商店元数据、隐私、日志和遥测开关。

## 3. 自动切图与差分压缩

Utage 的 Dicing 机制会把相似纹理切成网格，省略重复块和全透明块，再通过合成图重建原图；其官方文档建议将同一角色或同一事件 CG 的表情差分组成一组，并警告分组过大会增加同时加载的内存和时间。WorLd Studio 将吸收这一思路，并把分析、收益判断、质量验证和多平台输出做成自动化流水线。

### 3.1 目标与非目标

目标：

- 减少大量相似 CG、表情差分、口型、眨眼和序列帧的发布体积；
- 同时降低重复纹理造成的显存/内存浪费；
- 保留原始素材，不破坏创作者工作文件；
- 自动选择真正有收益的资源组，无收益时退回普通纹理。

非目标：

- 不把所有图片强制放入一个巨型图集；
- 不以肉眼不可见为借口在默认无损模式修改像素；
- 不把构建产物反写为唯一源素材；
- 不承诺切块对每种图片都比现代图片编码更小。

### 3.2 自动分析流程

1. 读取尺寸、Alpha、色彩空间、文件名、标签、场景引用和内容哈希；
2. 按角色、事件 CG、分辨率、章节和同时加载范围生成候选组；
3. 对候选图片建立缩略特征，计算整体相似度与变化区域；
4. 以多个候选 Cell Size 切块，并对标准化像素计算精确哈希；
5. 去掉完全透明块，合并精确相同块；
6. 将唯一块打包为一个或多个 Atlas，并生成每张原图的重建 Manifest；
7. 估算 Atlas、Manifest、Padding、Draw Call、加载组和平台纹理压缩后的总成本；
8. 只有达到项目设置的最小净收益时自动采用，否则保留原图；
9. 为 Windows、Web、Android、iOS 分别生成派生变体；
10. 输出节省空间、内存峰值、重建成本和风险报告。

### 3.3 分组策略

- 自动识别 `cg01_base`、`cg01_smile` 等命名关系，但不能只依赖命名；
- 相同尺寸、相同 Alpha 模式和高相似度是默认候选；
- 同一角色的表情/服装差分、同一事件 CG 差分优先成组；
- 不同章节且不会同时出现的内容默认分组隔离；
- 单组超过平台纹理、内存或首包预算时自动拆分；
- 用户可固定、合并、排除或锁定分组；
- 修改一个源文件时只重建受影响组。

### 3.4 模式

| 模式 | 行为 | 使用建议 |
|---|---|---|
| Lossless Dicing | 只合并逐像素完全相同的块 | 默认，CG/立绘首选 |
| Alpha Dicing | 同时消除全透明块 | 立绘、口型、眨眼、特效 |
| Delta Region | 保存共同底图与变化区域 | 大面积相同的事件 CG |
| Platform Texture | 对派生 Atlas 使用平台纹理压缩 | 正式构建，需真机验证 |
| Original | 不切块，仅常规编码 | 照片型背景、单张图、无净收益资源 |

有损平台压缩必须与无损去重分开配置，创作者可以保留无损切块但关闭有损压缩。

### 3.5 质量与安全

- 原图永久作为源资产，所有切块/Atlas/缩略图都是可删除重建的派生产物；
- 无损模式要求重建图与源图逐像素一致；
- 有损模式展示放大对比、差异热图、SSIM/感知指标和真机截图；
- Atlas 块使用 Padding/Extrusion，防止缩放和采样出现网格接缝；
- 自动测试不同缩放、旋转、滤镜、Mip 级别和透明边缘；
- 构建失败或运行时不支持时可按 Manifest 回退为普通纹理；
- 报告必须同时显示磁盘节省与运行时内存，避免“包更小但内存更高”。

### 3.6 编辑器交互

- 资源面板提供“优化建议”，显示候选组和预计收益；
- 一键自动优化默认只应用通过无损与收益门槛的组；
- Inspector 可预览源图、重建图、切块边界、重复块和差异热图；
- 可按资源、章节、平台查看优化前后容量；
- 任意自动决策可撤销、锁定或改为手动；
- 构建日志记录算法版本、参数、输入哈希和输出哈希，保证可复现。

## 4. 可调快进系统

### 4.1 快进模式

- **Skip Read**：只跳过当前存档元数据中已读的对话；
- **Skip All**：在项目允许时跳过未读内容；
- **Hold Skip**：按住按键/屏幕按钮时临时快进；
- **Toggle Skip**：再次操作前保持快进；
- **Preview Speed**：仅供制作时测试，不改变玩家设置。

### 4.2 速度配置

- 设置页提供滑杆和可读档位，例如 5、10、20、40 句/秒与 Instant；
- 项目可配置最小/最大值、默认值和是否开放 Instant；
- 文字、等待、转场、角色运动、音频、视频分别拥有快进策略；
- 即使 Instant 也必须按确定顺序执行状态命令，不能丢变量、解锁或调用；
- 选择、输入请求、错误、未下载内容和项目声明的 Stop Point 必须暂停快进；
- 快进退出后恢复正常动画、音频和文字状态，不遗留加速倍率。

### 4.3 自动播放不是快进

自动播放按可读性推进，综合文本长度、标点、语言和语音时长；快进以快速抵达目标为目的。两套速度和音频策略必须独立保存。

## 5. 每句/每步后退与前进

### 5.1 Story Step

系统为每条可观察语义命令生成稳定 `stepId`。默认检查点包括：

- 每句对白/旁白显示完成；
- 每个选择出现与选择提交；
- 每次场景/章节跳转；
- 每个显式 `checkpoint`；
- 创作者标记的重要演出步骤。

高级设置可允许按每个背景、角色、音频、变量或镜头命令单步。

### 5.2 玩家侧

- **后退**：恢复到上一 Story Step 的完整剧情与舞台状态；
- **前进**：在未产生新分支时沿已记录历史恢复下一 Story Step；
- 回退后改变选项、变量或输入将截断旧的前进分支，并保留在历史记录中供查看；
- 历史界面可选择某句回退；是否允许从历史前进由项目策略控制；
- 移动端提供明确按钮/菜单，默认不把危险回退绑定到容易误触的滑动；
- 回退边界、剩余步数和不可逆原因必须可见。

### 5.3 制作与调试侧

Debugger 提供 Step Back、Step Forward、Step Over、Continue、Run to Cursor：

- 可按对话级或命令级查看变量、调用栈、舞台和音频变化；
- 前后一步必须同步定位 Route、Sequence、Script 和 Stage；
- 在任意步骤修改工程后，旧执行分支标记失效并重新编译受影响片段；
- 可导出一段步骤日志用于复现 QA 问题。

### 5.4 可逆性契约

每个内建和插件命令必须声明：

- `pure`：无持久副作用，可直接重放；
- `reversible`：提供反向状态或可从检查点恢复；
- `barrier`：不可逆，回退到此处前必须停止并解释原因。

前后移动基于检查点、命令日志和确定性重放实现，不通过倒放动画猜测状态。

## 6. 自动生成路线图

### 6.1 创作者 Route Map

编译器从章节、场景、标签、选择、条件、跳转、调用、返回和结局自动构建图，不要求手工画第二份流程图。

- 脚本变化后增量更新；
- 全局为章节/场景图，场景内部可展开局部分支；
- 自动布局后允许保存纯视觉布局元数据；
- 标出不可达节点、死路、无出口循环、永真/永假条件和缺失目标；
- 显示变量条件摘要、预计时长、资源状态、翻译状态和测试覆盖；
- 可选择起点/结局生成可行路径，高亮当前试玩轨迹；
- 可导出评审图片、交互链接和机器可读图数据。

### 6.2 玩家流程图

从同一故事图自动生成，但应用剧透规则：

- 默认只显示已发现节点和已走连接；
- 未发现分支可完全隐藏、显示轮廓或显示数量；
- 节点可关联章节重玩或场景回想；
- 回到旧节点时由项目决定保留当前元进度还是使用当时状态；
- 完成率、路线名、结局和锁定提示均可配置；
- 创作者可手动调整展示名称、分组和坐标，但不能手工复制逻辑连接。

## 7. 自动生成画廊与附加页面

### 7.1 自动收集

编译器从资源标签和故事引用自动建立：

- CG Gallery：CG、事件图、差分组和查看状态；
- Scene Replay：场景入口、所需初始状态和退出目标；
- Music Room：BGM 标题、作者、封面、循环点和解锁条件；
- Ending List：结局名称、路线、达成条件和时间；
- Character/Glossary：人物资料、术语和分阶段解锁内容。

### 7.2 生成规则

- 首次在有效剧情路径展示 CG 时自动生成默认解锁条件；
- 同一差分组默认作为一个画廊条目，可选择展示全部差分；
- 自动生成多分辨率缩略图，缩略图是派生产物；
- 画廊模板自动生成分页、分组、完成率、锁定态和新内容标记；
- Scene Replay 从稳定检查点启动，在隔离状态运行，结束后返回原玩家状态；
- Music Room 自动读取实际音频循环和元数据；
- 创作者可覆盖标题、排序、封面、说明、剧透等级、解锁表达式和是否收录。

### 7.3 自动 QA

- 使用过但未收录的 CG；
- 收录但不可达或永远无法解锁的条目；
- 缺失缩略图、封面、标题、本地化或版权字段；
- Scene Replay 缺失初始变量、依赖前序下载或退出失败；
- 同一 CG 被误生成多个条目；
- 差分压缩组与画廊差分列表不一致；
- 四平台解锁、完成率和缩略图一致性。

## 8. 验收样例

Golden Project 新增 `Foundation` 与 `Dicing`：

### Foundation

- 覆盖 ADV/NVL、选择、保存、历史、自动、四类快进、逐句前后退；
- 自动生成含隐藏分支的创作者路线图和玩家流程图；
- 自动生成 CG、Scene Replay、Music Room 和 Ending 页面；
- 在 Windows、Web、Android、iOS 执行同一记录，状态与解锁一致。

### Dicing

- 至少 30 张同一事件 CG/立绘差分、透明立绘和不适合切块的背景；
- 自动分组能将合适差分纳入候选，并排除无净收益背景；
- 无损重建逐像素一致；
- 报告同时给出源容量、发布容量、峰值内存、Atlas 数量和加载时间；
- 多缩放、滤镜和真机截图无接缝；
- 修改一张差分只重建对应组；
- 删除派生产物后可以完全重建。
